{{ if eq . "2048" }}

使用 ↑↓←→ 或 WASD 移动。手机上在棋盘内上下左右滑动。

相同数字相撞会合并，合并的数字计入分数。每次有效移动会出现一个新方块，目标是合成 2048。

右上角可重新开始、暂停或切换音效；Space 也可暂停 / 继续。棋盘没有空格且无法合并时，本局结束。

{{ else if eq . "snake" }}

↑↓←→ / WASD 移动，手机使用棋盘下方方向控制。

Space 或点击棋盘暂停 / 继续；按住 Shift 加速。右上角可重开和切换音效。

18 格棋盘：粉豆限时连锁，棕豆造墙，黑豆清墙，金盾抵伤。避开蛇身和障碍。

{{ else if eq . "flappy-bird" }}

点击画布或按 Space 起飞，再次点击 / 按空格向上飞一下。手机直接点击画布。

穿过管道空隙得分，碰到管道或地面结束。右上角可重开、暂停 / 继续及切换音效。

{{ else if eq . "reaction-test" }}

点击测试区开始，等待颜色变绿后立刻点击。变色前点击不计成绩。

结果以毫秒显示，越低越好。右上角可开始新一轮、切换音效；打开说明会取消未完成的测试。

{{ else if eq . "typing-practice" }}

选择英文或中文 / 中英混打，在输入框中输入上方文字。第一次输入开始计时，完整输入正确文本后结束。

错字会标记出来，修改后可继续；中文输入法可正常使用。右上角可重开当前文章、随机换文和切换音效。

{{ else if eq . "gacha" }}

选择抽卡机制和卡池，再点击单抽或十连。右上角的重置会清空本次模拟进度。

{{ else if eq . "focus-timer" }}

选择时长或输入自定义分钟数，点击右上角播放图标开始。可暂停 / 继续，重置会回到设定时长。

音效图标控制结束提示音，音量和显示偏好可在设置区调整。完成后更新今日专注记录；记录保存在当前浏览器。

{{ else if eq . "random-number" }}

填写最小值和最大值，点击生成随机数，得到范围内的一个整数。

{{ else if eq . "audio-visualizer" }}

选择本地音频，或授权系统声音；也可以把音频文件拖入画布。

本地音乐支持播放列表、切歌、音量和进度调整。可切换显示模式或全屏展示。

常见音频标签会自动读取；没有曲绘时，点击图片图标手动选择。曲名旁的设置可填写当前歌曲的曲名、作者和采样率标注，关闭后自动保存，切歌或列表循环仍保留；恢复自动识别可清除手填信息。

手填采样率只影响展示，不改变音频。播放中返回会清空本次列表并回到音乐初始界面，在初始界面再次返回才离开工具。返回初始界面、刷新或离开工具后不保留信息；文件仅在浏览器中处理，不会上传或改写。

空格暂停 / 继续，进度条支持拖动和方向键。律动默认开启，跟随系统的“减少动态效果”设置。系统声音取决于浏览器共享音频能力，不提供歌曲信息；移动浏览器可能不支持。

频谱与波形来自实时分析。循环图标可切换列表循环、单曲循环和随机播放；播放列表默认收起。无声时不伪造频谱，减少动态效果模式下不摆动组件。
