# v20.18.5 音频可视化返回键回初始界面

## 修复

用户希望音频可视化里的返回键先返回该工具的初始界面，而不是直接返回工具页。

本版逻辑：

1. 如果正在播放本地音频 / 浏览器音频 / 可视化 live 状态：
   - 阻止默认跳转
   - 执行 `resetToInitialView()`
   - 停止音频和流
   - 清除 live 状态
   - 显示初始选择卡片

2. 如果已经在音频可视化初始界面：
   - 再次点击返回键才跳转 `/tools/`

## 保持

- 右上角仍无“停止”按钮
- 返回键外观保持小圆形原样
- 返回初始界面时会释放音频资源
