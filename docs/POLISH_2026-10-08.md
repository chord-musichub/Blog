# 展示与日常使用打磨（2026-10-08）

本轮保留现有 Hugo/Go 技术方案、页面布局、主题、朋友行星轨迹和工具功能，不新增装饰模块或第三方依赖。不部署、不修改用户文章、媒体、账号或生产配置。

## 修复

- 首页留言详情使用原生模态 dialog，阻止背景接收鼠标/键盘焦点；支持 Escape、背景点击、关闭按钮和关闭后返回原留言。快速关闭再打开时拒绝迟到的 close 事件，换页开始即关闭顶层弹窗。面板尺寸、背景、边框、排版与修改前对照一致。
- 首页留言提交增加单次进行中的保护；超时、网络错误、5xx 或无效响应不会换地址重发可能已经保存的留言。只有明确的 404/405 可尝试配置的备用接口。每个请求的响应头/正文等待最多 8 秒，离页中止请求。前端防重发不等于服务端幂等性，超时仍可能已保存，提示先重新查看而不是立即再次提交。
- 提交失败保留输入和预览状态；无效响应不再当作成功清空表单。初次读取失败不冒充「0 条留言」，显示简短错误，重新打开可重试。迟到的初始读取不能覆盖刚提交成功的新列表。
- 空内容不隐藏必填输入去展示预览；输入法确认不误打开留言详情。面板切换取消旧的延迟聚焦，离开后不再更新旧页面。
- 五个小游戏及两个排行榜模块统一使用 `SonglineRuntime.storage`：浏览器禁止存储或配额已满时退化为本页面内存，不因保存最佳成绩、音效偏好或玩家 ID 失败而中断游戏。站内局部切页可以保留内存数据，刷新或关闭页面后不保证保存；不改变浏览器原生 Storage，也不替代隐私偏好/认证存储。
- 打字工具的计时更新使用模式内的最佳成绩缓存，不再每 80ms 读取同步存储。重新开始、切换模式和其他标签页的 storage 事件会刷新缓存。排行榜用请求代次拒绝旧模式/旧请求的迟到结果，离页取消请求，不把英文成绩写进混打缓存。
- 随机数工具先规范上下界，再向整数区间取整；拒绝空输入、无整数区间和超出安全整数精度的范围。`0.2–0.3` 不再生成范围外的 `0` 或 `1`，输入法 Enter 不触发生成。

## 回归范围与复现

所有浏览器请求拦截至本地构建、图片夹具和模拟接口。测试中的留言发布、成绩提交均不进入生产服务。浏览器为本机 Edge/Chromium，移动视口不是物理手机。

```sh
GOPROXY=off GOTOOLCHAIN=local go test -mod=vendor ./...
node --test tests/*.test.cjs

# BLOG_UI_BUILD 必须是最新构建。可选的 BASELINE 用于对照留言弹窗外观。
BLOG_UI_BUILD=local-only/polish-2026-10-08/final/public \
BLOG_UI_BASELINE=local-only/polish-2026-10-08/public \
node tests/demo-polish.browser.cjs

BLOG_UI_BUILD=local-only/polish-2026-10-08/final/public node tests/stability.browser.cjs
BLOG_UI_BUILD=local-only/polish-2026-10-08/final/public node tests/tool-detail-layout.browser.cjs
BLOG_UI_BUILD=local-only/polish-2026-10-08/final/public node tests/reading-polish.browser.cjs
BLOG_UI_BUILD=local-only/polish-2026-10-08/final/public node tests/tool-icons.browser.cjs
BLOG_UI_BUILD=local-only/polish-2026-10-08/final/public node tests/archive-pagination.browser.cjs
node tests/external-resources.browser.cjs
```

浏览器测试需可用的 Playwright、pngjs 和本地 Edge；本轮使用工作区现有运行时，没有安装依赖。截图与构建保存在被忽略的 `local-only/polish-2026-10-08/`，其他专项报告沿用各测试的本地输出目录。

- 新专项：390px/1440px 深浅主题弹窗外观对照、焦点约束、快速重开/离页；模拟重复提交、5xx、无效 JSON、超时、备用接口、草稿保留、读取恢复、迟到读响应；禁用存储/配额耗尽下五个工具的实际操作；定时更新不读存储、跨标签最佳成绩更新和乱序模式排名。
- 工具专项：320、390、820、1440px，覆盖深浅主题、实际操作、说明弹窗、图标状态、外置排行榜和局部换页。
- 阅读专项：390、1024、1440px，覆盖深浅主题、文件替换、六级目录、预览布局、返回 hover/焦点以及刷新加载器。
- 全站专项：主页、十个工具直开，桌面深浅主题和手机三轮反复导航，检查目录命中区、朋友/回忆拖拽、历史前进返回、文件 URL/音频上下文释放及 DOM/监听不逐轮积累。
- 第三方专项：图标正常/不可达、搜索/滚动/重入、图片有限恢复、迟到响应、换源、离页及已显示正文图片的复用。

## 本轮验证结果

- 离线 Hugo 构建成功：178 个页面、231 个静态文件；Go 测试和 27 个 Node 测试文件全部通过，JavaScript 语法检查及 `git diff --check` 通过。
- 新增留言/存储/随机数专项，以及既有稳定性、工具布局、阅读、图标、第三方资源和档案分页浏览器回归全部通过。
- 全站连续三轮导航中，桌面深色每轮均为 2346 个节点/504 个监听，桌面浅色为 2347/504，手机深色为 1664/484；未发现逐轮积累或页面 JavaScript 异常。这是本地受测场景的结果，不代表长期负载结论。
- 既有全站回归使用 `after/public` 构建；最终 `final/public` 仅完善提交结果不确定时的提示，新增专项已使用最终构建重新通过。

## 上线与作业演示边界

需要正常重建并发布后，线上才会使用新模板和资源。未修改后台权限或 giscus 的 GitHub 管理流程。第三方实际网络可用性、线上账号鉴权、物理 iOS/Android、服务器负载不在离线测试结论内，不能宣称网站绝无故障。

演示前用准备好的测试账号确认登录、保存草稿、修改/删除测试文章、媒体管理等真实权限流程；不使用正式内容做破坏性演示。报告如实写明 Hugo、原生 JavaScript 与 Go，以及按需加载、生命周期清理、响应式布局和失败降级的实现。老师认可框架选择不代表免除其他作业要求。
