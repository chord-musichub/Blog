# v20.18.5 音频可视化大卡片舞台修复

## 问题

v20.17.0 将音频可视化改成 full-bleed 横向铺满，但用户希望它仍然是“卡片显示方式”，而不是横向占满全屏。

## 修复

本版改为“大卡片舞台”：

- 页面背景仍保留
- `.av-stage` 作为唯一大圆角卡片
- 大卡片占据导航栏下方大部分空间
- 不横向贴满屏幕
- 桌面端宽度为 `min(1540px, 100vw - gap * 2)`
- 高度为导航栏下方剩余高度
- live 状态也保持大卡片，不再横铺
- 控制按钮仍为页面级浮动按钮

## 说明

这版不是回到小卡片，而是介于两者之间：

```text
不是 full-bleed 横铺
也不是小舞台
而是大号圆角沉浸卡片
```
