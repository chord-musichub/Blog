# v20.18.5 音频可视化歌曲卡 / 返回键 / 打开新文件修复

## 修复 1：左下角歌曲卡被裁切

本地上传音频进入播放后，左下角歌曲信息卡被舞台底边裁切，只露出一部分文字。

本版强制：

- `.av-now` 绝对定位在舞台内部
- `bottom` 留出安全距离
- 设置固定最小高度
- 降低内部标题/封面尺寸
- 保持玻璃卡片样式

## 修复 2：返回键同步右上角按钮效果

返回键不再是旧的小圆形按钮。  
现在同步右上角控制按钮的玻璃质感：

- pill 胶囊形态
- 文字「返回」
- hover / focus 反馈一致
- 移动端自动回到图标按钮，避免挤压

## 修复 3：打开新文件后直接播放

问题：选择同一个文件时，file input 不会触发 change，因此“打开新文件”看起来没效果。

本版处理：

- 打开文件选择器前先 `fileInput.value = ''`
- handleUpload 会 pause / clear / load 旧音频
- 设置新 `src`
- `currentTime = 0`
- 直接播放新音乐
