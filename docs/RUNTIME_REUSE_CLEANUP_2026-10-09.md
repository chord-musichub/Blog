# 运行时复用与去冗 · 2026-10-09

基线为已提交的 `95001fa`。本批继续优化现用组件，不修改 CSS、模板、图标形状或布局；重点是减少反复重建、重复绑定和重复写入，而不是删除仍在使用的功能。

## 音频列表

- 歌曲对象作为稳定键，新增/移出歌曲才调整列表结构；切歌只更新前后两行的选中状态，元数据和手动设置只更新对应行文字。
- 列表统一使用一条委托监听，移出后校验最新下标与行身份，避免播放错位。退出工具释放列表节点、映射和监听。
- 缓存固定播放图标、队列计数和播放模式图标，减少重复查询。
- 删除只有写入、没有实际消费者的播放模式/收缩 class、专辑与来源展示字段、parsed 标记、重复文件名计算及第二次来源卡片绑定。保留公共元数据解析 API、作者/采样率/曲绘、手动设置、循环模式和原有紧凑布局。

## 共享图标

- 浏览器会把 SVG 自闭合标签序列化为完整闭合标签；原先与注册表原字符串比较，会把相同图标误判为变化。按浏览器序列化结果缓存比较，未变更图标不再替换子节点。
- 图标名称变更、注册内容更新或节点被外部修改仍会正确恢复；不使用可能过期的元素缓存。
- 保留换页后 20ms / 120ms 两次校正，但新换页、离场和 pagehide 会取消旧任务；最多保留两个定时任务，跳过断开的旧根节点。

## 文章留言

- `pagehide.persisted` 保留 giscus iframe 和绑定，缓存恢复时仍能互动；永久离场与站内切页才销毁。
- 同主题消息、同高度和重复 ready 状态不反复写入。真实 iframe load 仍强制同步主题，防止加载前发送的消息丢失。
- 保留来源/窗口校验、按需加载、超时重试和 GitHub 登录逻辑；未连接线上评论或修改账号/评论数据。
