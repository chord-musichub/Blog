# v20.18.5 音频可视化视口比例与控制按钮修复

## 修复 1：卡片位置错位

问题：音频可视化舞台按整屏高度计算，但页面顶部还有站点导航栏，导致卡片被挤到舞台下方甚至露不完整。

本版处理：

- 新增 `--av-page-nav-offset`
- 舞台高度改为 `100svh - nav offset`
- 初始态来源卡片按舞台自身高度定位
- 来源卡片固定在舞台下方但完整显示
- 高度不足时降低标题与卡片高度
- 中小屏回退自然流

## 修复 2：控制按钮被卡片/舞台裁切

问题：live 后全屏 / 停止按钮仍被 `.av-stage` 的 overflow / clip-path 裁切，看起来像只露在卡片内部。

本版处理：

- live 后 `.av-stage` 取消 overflow/clip-path 裁切
- 控制按钮 `position: fixed`
- z-index 提高到 9999
- top 改为导航栏下方
- 按钮不再半截显示

## 修复 3：浏览器系统声音不显示歌曲卡

`is-browser-audio-live` 下强制隐藏 `.av-now`。
