# 前台切页、工具搜索与失用代码清理 · 2026-10-09

## 目标与实现

保持现有外观、功能和动画节奏，减少切页资源等待与搜索重复写入。基线为 `d5db10d`，没有提交、推送或部署。

- 目标 HTML 返回后立即读取、解析和处理旧标签跳转；所选主题场景与同源 CSS preload 在原幕布覆盖期间准备。覆盖完成后才应用页面壳、按既有顺序应用 CSS、替换正文和初始化模块。覆盖与揭幕仍各 480ms；未缩短动画。
- preload 保留完整 URL、media、integrity 等原链接属性，只选择当前匹配的同源样式，跳过已有资源，并在成功/失败后移除。结束时取消请求，早期失败有拒绝处理并沿用原整页回退；不增加 HTML 缓存、悬停预取或公开 API。
- 工具搜索缓存当前页面的分层/卡片成员，按实际 DOM 状态跳过重复 hidden、display 和计数写入。外部修改仍会被修正；统一复用搜索流程处理清空，保持匹配、分层、提示、焦点和 URL 初始查询。
- 核查发现星图模板已没有搜索入口。用户明确选择删除失用的星图搜索 JS 及专用 CSS，并将搜索优化转向现用工具页面。星图头像、连线、拖拽、缩放及资料聚焦不变。

## 测量条件

- Intel(R) Core(TM) i9-14900HX，Headless Chrome 154.0.8037.97；视口 1440×900 / 390×900，CPU 节流 1× / 4×，同硬件、内容和构建参数，浏览器测试串行运行。
- 使用本地已有 Hugo 0.125.4 镜像离线构建；前后均 61 页、174 个静态文件。固定 16 篇测试文章、公告和公开朋友种子；不复制运行时账号、草稿、统计或用户上传。
- 前台保留正常动画及实际本地图片。HTTP 替身固定增加 HTML 40ms、CSS 180ms、场景背景 300ms；API 由本地固定 JSON 响应，外部资源由 CSP 阻断。外部头像替换为本地种子，原图预览 URL 返回原图，不代表线上预览缓存表现。
- “冷缓存”每次切页清 HTTP 缓存；“暖缓存”先访问全部路线。当前文档的模块状态、已应用样式及解码状态保留，不能称作完整冷启动。
- 每个视口/CPU/缓存/版本组合 10 次切页，按固定顺序访问档案、文章、星图、回忆、工具、首页，共 160 个最终计时样本；每条路线不是单独 10 次。总耗时包括原有动画，等待时间从覆盖完成到揭幕开始。
- 每个视口/CPU/版本/规模组合 100 次输入，共 1600 次；相邻输入包含相同结果。现有 37 张工具卡片与 300 张固定克隆卡片分别报告。事件处理时长通过同步派发输入事件测得，双 RAF 时长仅是呈现机会代理，不是生产 INP。
- 首次 fixture 使用 RawContent，被旧版 Hugo 双重转义。已改为后台使用的 Base64 源格式后重新构建、跑完回归和性能矩阵；初次数据 `performance-initial-fixture.json` 与 smoke 报告不用于最终结论。

- 37 卡片的 100 次输入：结果列表 DOM 变更 7,478 → 2,233；300 卡片为 48,290 → 28,016。变更计数包含属性及子节点，不是同时存活的节点数。
- 相同结果连续重复输入 20 次：优化后列表 DOM 变更为 0，既有节点保留。
- 同步处理工作减少，但呈现 p95 基本不变；300 卡片 / 4× CPU 的呈现尾部仍约 117ms，不声称消除了压力场景卡顿。
- 五个修改资源源码合计 105,349 → 103,262 字节（−2,087）；独立 gzip 合计减少 365 字节。普通页面的切页与搜索保护逻辑增加字节，朋友页失用规则减少字节，不能当作每页均等的传输节省。

### 回忆页慢样本复核

桌面 4× CPU / 冷 HTTP 缓存首次完整矩阵中，回忆页一个样本为 1868.1 → 2040.5ms；没有据整体中位数忽略它。反转版本运行顺序（after → before），交替访问星图与回忆，每条路线每版本再测 10 次：

| 路线 | 总耗时中位数：前 → 后（ms） | 全样本范围：前 → 后（ms） |
| --- | --- | --- |
| /friends/ | 1610.5 → 1367.1 | 1534.3–1806.7 → 1345.3–1692.6 |
| /friends/memories/ | 1989.2 → 1805.5 | 1762.9–2400.9 → 1559.6–2046.7 |

复测回忆页中位数下降约 9%，范围仍重叠；没有复现持续退步。混合路线 n=20 的 p95 为 2172.9 → 2010.2ms，仅作为这次复核样本的描述，不外推可靠生产尾延迟。原始数据为 `memory-repeat.json`。

## 验证与保护指标

- 最终矩阵和异常样本复核共 200 次计时切页，异常失败 0/200，计时区间累计 287.3 秒（不含启动、预热、构建）。这是本地固定负载记录，不是生产故障率。
- 前端单元测试 177/177，通过新增早期准备、头/体失败、旧标签目标、覆盖失败清理、重复状态与外部修改纠正测试。
- 搜索前后 28 组场景输出一致，覆盖大小写、中文输入、标点、空查询、无结果、Enter、Escape、原生清空、自定义清空焦点及重新进入页面。
- 4 组视口/动态偏好下的排队导航、Back/Forward、文章深链接、旧标签原名跳转通过；HTTP 和 CSS 503 均执行完整文档回退，无意外脚本异常。额外验证 CSS preload 只传输一次，预热期间旧正文、主题和样式保留。
- 24 组真实图片视觉对照：几何与检查的计算样式相同，无横向溢出；平均通道差最大 0.0341/255。动画只在截图阶段冻结，Canvas 遮罩；不声称动态场景逐帧完全一致。
- 减少动态效果下桌面/手机各 10 轮、每轮 5 次切页：第 3–10 轮文档数均 2，监听均 268；桌面节点 413，手机主要为 409（单次 422 后回到 409），无逐轮增长；该采样点全部四类待执行任务为 0。
- 正常动画下桌面/手机各 10 轮也通过：1440px 文档 2 → 2、节点 437 → 437、监听 289 → 289；390px 文档 2 → 2、节点 421 → 421、监听 282 → 282。每轮采样均为 1 个待执行 setTimeout，其余三类任务为 0，无逐轮增长。正常动画与减少动态效果的 JSON 分别保存在 `regressions-lifecycle.json` 和 `regressions.json`。

## 复现

准备独立源码目录后，用当前测试工具生成固定公开数据：

```bash
node tests/prepare-interaction-build.cjs /path/to/baseline /tmp/blog-audit/before
node tests/prepare-interaction-build.cjs /path/to/current /tmp/blog-audit/after
hugo --source /tmp/blog-audit/before --destination /tmp/blog-audit/before/public --minify
hugo --source /tmp/blog-audit/after --destination /tmp/blog-audit/after/public --minify
export INTERACTION_VARIANTS='{"before":"/tmp/blog-audit/before","after":"/tmp/blog-audit/after"}'
node tests/interaction-performance.browser.cjs
node tests/interaction-regressions.browser.cjs
INTERACTION_REGRESSION_ONLY=lifecycle INTERACTION_LIFECYCLE_MOTION=normal node tests/interaction-regressions.browser.cjs
node --test --test-isolation=none tests/*.test.cjs
```

基线源码可从 `d5db10d` 导出；需要同一 Hugo 版本、Playwright、Sharp 和 Chrome，包不在默认路径时设置 `NODE_PATH`，浏览器路径用 `BLOG_BROWSER_PATH` 指定。输出目录须不存在，工具拒绝覆盖既有 fixture。镜像构建使用 `--network none`，只挂载测试目录。

原始性能、回归 JSON 和截图在忽略目录 `local-only/interaction-2026-10-09/`；这些产物不部署、不提交。Go 后端未改动，本轮未重复后端测试，也不引用历史结果冒充本轮验证。
