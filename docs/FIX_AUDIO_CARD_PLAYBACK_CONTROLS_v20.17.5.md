# v20.18.5 音频可视化卡片与播放控制修复

## 修复 1：大卡片不再像“镶在页面里”

本版调整音频可视化大卡片：

- 减小外侧 gutter
- 宽度改为 `100vw - gutter * 2`
- 保留圆角卡片感
- 但不再显得像小卡嵌在页面中央
- live 状态同样保持圆角大卡片

## 修复 2：返回键对齐

返回键现在固定到音频大卡片左上角附近：

```css
left: card gutter + 18px
top: nav height + card gap + 18px
```

不再贴页面最左，和工具页视觉更同步。

## 修复 3：全屏/停止/打开新文件控制区

live 状态下右上角控制区新增：

- 打开新文件
- 全屏显示
- 停止
- 音量控制

控制区固定在可视化卡片右上角。  
进入真正 fullscreen 后，控制区回到全屏右上角，不再留导航栏空余。

## 修复 4：本地文件空格暂停

本地音频播放时：

- Space 暂停
- Space 继续播放

当焦点在按钮、输入框、进度条等控件上时，不抢占空格行为。
