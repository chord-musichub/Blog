# 画册式文章详情页（2026-10-10）

详情页采用“完整封面 → 日期、作者 → 标题 → 打字简介 → 阅读信息、标签和下载 → 正文”的阅读顺序。封面、资料和正文沿同一阅读轴，保留外围一层场景玻璃底板，移除头部与正文重复的卡片边框、背景和阴影。

封面按图片原比例缩放，无固定 16:9 框、色条或文字遮罩。桌面最大高度 520px，手机最大高度 50svh，竖图居中收窄；8px 圆角与轻微阴影只作用于图片。保存的封面图片 URL、加载优先级和缺省封面配置保留。详情页完整展示当前保存的图片；按用户确认，后台裁剪后详情页继续使用保存的裁剪封面，不恢复裁剪前的原图。既有 `cover_mode` 数据和档案展示保持原样。加载期间提供占位和状态文案，失败后显示可翻译的提示；恢复有效图片时回到正常展示，不阻塞文章操作。

简介资料与正文之间增加贯穿阅读轴的 2px 分界线，深浅主题分别使用对应的灰蓝色，线条上下保留留白。图文间距桌面 28px、手机 20px。标题分别为 32px / 26px，简介 15px，辅助信息 12px。日期和作者靠近标题；阅读信息、文字标签及图标加文字的下载按钮在简介之后自然换行。长标题、作者名和标签允许折行。下载状态只更新按钮标签，保留图标、焦点和原下载行为。

简介沿用一次性字素动画及原文布局层，动画不修改作者内容、不会带动正文跳动。减少动态效果直接显示原文；离场、隐藏和卸载释放动画任务与监听。目录、档案点击抽屉、历史返回保持原行为。样式只在具有 `data-article-layout="album"` 的文章详情页生效，不覆盖 Markdown 预览工具。
