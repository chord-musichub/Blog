# v20.18.5 贪吃蛇吃果实后停止修复

## 问题

v20.13.5 中吃到果实后，游戏可能直接停止。

## 根因

v20.13.5 为了增强豆子图标清晰度，把部分线宽改成按比例缩放。  
其中有几处本应使用全局 `cell` 的地方误写成了 `size`。

`size` 只在 `drawFoodIcon` / 墙体 / 蛇身绘制内部局部存在。  
在粒子绘制、清屏豆外圈、临时豆倒计时外圈里使用 `size` 会触发：

```text
ReferenceError: size is not defined
```

吃果实后会出现加分粒子，所以错误会立刻触发，导致 requestAnimationFrame 循环中断，看起来就像“吃了虫子后停止”。

## 修复

1. 将粒子绘制中的 `size` 改为 `cell`
2. 将清屏豆外圈绘制中的 `size` 改为 `cell`
3. 将临时豆倒计时外圈绘制中的 `size` 改为 `cell`
4. 给主绘制循环加轻量 try/catch，避免未来单次绘制异常直接杀死整个游戏循环

## 影响范围

只修复 bug，不调整玩法参数。
