# 稳定性与运行时性能（2026-10-07）

本轮以保持当前主题、布局和行星轨迹为约束，重点检查朋友星图，并覆盖回忆页和全站动画恢复。旧标签漂流带仍然退役。本轮不部署、不修改用户文章、上传媒体、账号、运行配置或依赖。

## 修复与优化

### 朋友星图

- 布局校准复用 SVG 连线节点，不再清空并重建整组边。尺寸、节点位置、透镜和边端点在同一次布局中更新，不先绘制上一份坐标再等待下一轮帧回调。
- 帧内透镜计算复用节点投影对象，以缓存值判断属性变化；删除每帧读取各头像 CSS 自定义属性的工作，避免分配整份圆心映射。视觉公式、放大倍率、柔焦遮罩与配色不变。
- 仅由页面模块调度器初始化，移除竞争的 DOMContentLoaded / page-swap 自启动。清理时解除 ready 标记、局部与全局监听、延迟布局与帧回调，已清理但仍连接的 DOM 可以重新初始化。
- 隐藏、失焦或缓存暂存时中止拖拽、惯性与缩放；缓存恢复重新校准，但不销毁暂存页的交互。字体等迟到回调在控制器已清理时不再安排工作。动态减少动画偏好会立即生效。
- 站内成员有 `username` 但没有 `url` 时使用已生成的本地资料页；没有用户名/网址的第三方节点不伪造地址。资料跳转使用现有站内转场与历史，拖动主头像释放时不误跳转。
- 忽略重复身份，避免节点映射与边坐标互相覆盖。显式空关系配置不再被默认关系/自动链覆盖。

### 保留的行星轨迹

- 重复初始化不覆盖 `is-visible` 或重播渐入；只有新增图层才安排渐显。
- 启动、空闲任务、开机等待与恢复任务单例化。切页/隐藏/离开时取消计时器、观察器和帧回调，使用任务代次拒绝迟到回调。
- 等待开机结束时只观察根节点及实际遮罩属性，不观察整个正文的子树/样式变化。桌面保留变形与描边动画，手机保留原有静态轨迹，减少动画偏好可即时移除/恢复。

### 公共运行时及回忆页

- `SonglineRuntime` 增加成对的 `cancelIdle(key)` / `cancelRaf(key)`；取消时区分原生 idle 与超时兜底，不再用错误的取消 API，也不保留完成任务的键。
- 全站 WAAPI 动画恢复共用一条帧循环，而不是每个动画各一条。快速隐藏时恢复原目标速率，避免把临时 `.18x` 当成下一次的正常速度而反复减速。结束、暂停及脱离文档的动画退出恢复集合。
- 回忆页同样只用模块调度入口；支持连接 DOM 清理重入、缓存暂存/恢复与失焦中断。resize 合并到帧，清理时关闭图片弹窗和全部监听，避免遗留交互状态。

## 可复现的工作量变化

离线同内容夹具包含 19 个朋友、48 条边；在桌面/手机、深浅主题下执行相同拖拽、四次尺寸变化和每轮八次重复轨迹初始化。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 同一轮测试移除的连线节点 | 384 | 0 |
| 轨迹丢失 `is-visible` 的次数 | 8 | 0 |
| 拖拽期读取透镜 CSS 属性，桌面 | 1,482 | 0 |
| 拖拽期读取透镜 CSS 属性，手机 | 1,368 | 0 |
| 20 个动画恢复所需的独立待执行帧回调，单元夹具 | 20（旧算法） | 1 |

完成后的连线与轨迹节点保留身份；连续请求开机等待只注册一个 interval，离开后为零。三轮全站切页后，手机节点/监听分别稳定在 824/192，桌面为 854/192。手机全部工具正常动画重入测试的节点/监听稳定为 1,685/479，未见持续增长。

这些是固定事件序列的 DOM/调度工作量，不是公网延迟或真实手机 FPS 保证。为补齐取消和恢复保护，本轮源码有所增加，没有减少资源请求或依赖；不能把这轮称为文件体积优化。外观对比测试可用 `CLEANUP_RUNTIME_ONLY=1` 跳过“字节必须减少”的历史清理断言，几何、样式、像素及功能断言仍保留。

## 验证入口

- 离线 Hugo 构建（178 页）、Go vendor 模式及 22 个 Node 单元测试文件。
- `stability-performance.test.cjs`：恢复帧链合并、快速后台切换速率、暂停/脱离动画、idle 兜底取消、重复身份与单一初始化入口。
- `stability-performance.browser.cjs`：上述四组对照压力测试；真实触屏拖拽、开机等待取消、动态减少动画、缓存/可见性事件恢复、同 DOM 三次重新初始化、主头像拖动保护与资料转场、回忆弹窗重入、空关系配置与重复身份。
- `galaxy-lens.browser.cjs`：头像与边端点误差、拖拽/释放的透镜一致性、背景柔焦、缓动缩放及缩放后尺寸变化。
- `cleanup-performance.browser.cjs`：18 个现用路由 × 手机/桌面 × 深浅主题，共 72 对布局、样式和截图；装饰动画冻结、Canvas 屏蔽，真实操作另外测试。
- `runtime-optimization.browser.cjs` 生命周期模式：手机/桌面三轮档案、公告、阅读、工具、朋友、回忆、首页切换，检查样式恢复及 GC 后节点/监听。
- `stability.browser.cjs` 手机正常动画模式：全部工具三轮重入、交互、历史导航、音频和本地文件资源释放。

全部测试请求使用本地构建与 API/媒体夹具，不请求线上数据。缓存事件使用可控生命周期事件夹具，不能据此声称所有实际手机浏览器和 GPU 驱动都已验证。构建、截图、对照报告在忽略目录 `local-only/stability-performance/`；生命周期与工具报告沿用各自测试的忽略目录。
