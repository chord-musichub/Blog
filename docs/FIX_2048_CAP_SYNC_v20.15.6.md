# v20.18.5 2048 封顶与本地成绩同步修复

## 问题

朋友达成 2048 后，本地最高分保留了，但没有进入服务器前三名。

## 根因

旧逻辑只在棋盘真正无法移动时提交分数；达成 2048 只是胜利状态，不一定触发 game over，因此不会同步。

## 本次修复

### 1. 2048 不再作为结束条件

达成 2048 后：

- 游戏继续进行
- 不弹出遮挡式胜利层
- 播放胜利音
- 立刻尝试同步当前分数

### 2. 2048 方块封顶

两个 2048 不再合成 4096。

- `canMove()` 不再把 2048 + 2048 视为可合成移动
- `move()` 只允许小于 2048 的同值方块合成
- 合成结果最大值为 2048

### 3. 本地最高分同步服务器

页面加载后会自动尝试同步本地最高分。

新增按钮：

```html
<button data-2048-sync-best>同步本地最佳</button>
```

用于朋友已经在本地保留最高成绩，但服务器没有记录时手动补救。

### 4. 服务器排行榜按账号 / 设备保留最佳

2048 排行榜后端改为：

- 登录账号按账号归并，只保留最高分
- 未登录游客按浏览器匿名 ID 归并，只保留最高分
- 最后从所有账号 / 设备最高分中取前三

旧的无身份记录仍作为 legacy 记录兼容。
