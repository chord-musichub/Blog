# v20.18.5 2048 防闪烁动画收尾

## 问题

v20.14.2 中 2048 已经有真实滑动动画，但部分方块在移动/合成结束时仍会闪现一下。

## 根因

旧实现中，移动结束后会立刻：

1. 删除旧 DOM
2. 创建最终 DOM
3. 创建合成块
4. 创建新数字块
5. 重新渲染 tile 层

这些动作如果落在同一帧，浏览器可能会把 transform / class / DOM 创建合并处理，造成一帧闪烁。

## 本次修复

### 1. 两阶段提交动画

移动阶段：

- 保留旧数字块 DOM
- 只更新 transform，让它们滑到目标格

收尾阶段：

- 等移动结束后，再删除被合成吃掉的旧块
- 分帧渲染合成块
- 延迟生成新 2/4

### 2. 新块延迟出现

新生成的 2/4 不再和移动动画抢同一帧。  
会在移动结束后稍微延迟出现，减少闪现。

### 3. 合成块独立 pop

合成块使用 `is-merged` 动画，等旧块滑完后再弹出。

### 4. no-transition 防止重排跳变

在 resize / 首次渲染 / 收尾重绘时使用 `no-transition`，避免浏览器误触发位移动画。

## 影响范围

只修改 2048 的 JS 和 CSS，不动贪吃蛇、不动工具页结构。
