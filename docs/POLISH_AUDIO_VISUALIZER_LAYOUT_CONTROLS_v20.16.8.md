# v20.18.5 音频可视化布局与控制按钮优化

## 优化 1：入口卡片比例 / 位置调整

音频可视化入口三张来源卡片从简单流式布局改为舞台内绝对定位：

- 桌面端卡片位于下方视觉区域
- 三列等宽
- 统一最小高度
- 高度不足时回退为普通文档流
- 中小屏回退为单列

## 优化 2：浏览器系统声音不显示歌曲信息小浮窗

网页登录/浏览器授权系统声音只能拿到频谱，拿不到播放器歌曲信息。  
本版接入浏览器系统声音后：

- 不显示左下角歌曲信息小卡
- 只显示可视化和页面级控制按钮

本地助手模式如果读到真实歌曲名，仍可以显示左下角迷你歌曲信息。

## 优化 3：正式进入可视化后控制按钮页面级显示

live 状态下：

- 全屏显示 / 停止按钮固定在页面右上角
- 不再依附于歌曲小卡
- opacity 直接为 1，避免找不到按钮
- 移动端改为底部双按钮

## 修改范围

- `layouts/tools/audio-visualizer.html`
- `static/js/tools/audio-visualizer.js`
- `static/css/site.css`
- 本地助手下载包版本号同步
