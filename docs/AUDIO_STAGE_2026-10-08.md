# 音频可视化：音乐舞台重构

以参考图的「曲绘＋信息＋分析」层次重新设计，不复刻参考图。按用户后续要求，工具改为独立全屏音乐界面：不展示地下背景、站点顶栏、Logo、电梯、地图或页脚，不保留工具玻璃外框。当前曲绘铺满屏幕并虚化，配合深浅色遮罩、浮动封面与轨道；桌面大曲绘和大标题分列，手机纵向排列。播放控制不参与摆动，避免命中区漂移。

## 功能与边界

- 本地音乐、拖入多首、上一首/下一首、暂停/继续、音量、可拖动和键盘控制的进度条、三种循环模式；模式与列表合为一个小控件。歌曲列表默认关闭，原生浮层展开不撑高舞台；点击外部或 Escape 关闭，键盘关闭恢复触发按钮焦点。原生浮层在浏览器全屏中也可见；旧浏览器保留固定浮层降级。
- MP3 / FLAC / WAV / M4A 的常见内嵌标题、作者、采样率按选中曲目懒读取并缓存，MP3 / FLAC / M4A 可读取曲绘。MP3 支持 ID3v2.2/2.3/2.4、扩展头及 ID3v1 回退，FLAC / M4A 优先歌曲作者而非专辑作者。标题缺失使用文件名，作者缺失明确显示「未知作者」，不把专辑名称冒充作者。
- 首次解析限文件前 16 MiB，MP4 只跳读末尾 moov 容器（限 16 MiB），MP3 必要时读取末尾 128 字节。容器遍历有深度/数量边界，超大或不支持的标签可能不完整，不影响播放；不为采样率解码整首音乐。原文件采样率优先展示；只取得 AudioContext 采样率时标注「分析」，提示不代表原文件采样率。
- 作者/采样率旁的设置图标打开当前本地曲目的信息弹窗，可修改曲名、作者和采样率标注。关闭、Escape 或点击模糊背景时校验并保存，无需额外保存按钮；采样率接受 1–768000 的整数 Hz，非法值需修正。每首曲目的 overrides 与自动读取的标签分开，手填优先，迟到解析不覆盖；只保存实际修改的字段，避免打开后直接关闭把旧标签冻结为手填。清空字段恢复该字段自动识别，恢复按钮清除全部手填。
- 设置保存在本次内存播放列表内，切歌/列表循环继续有效，返回音乐初始界面、刷新或离开工具不保留，不改写源文件或上传。编辑对象绑定打开时的曲目引用，自动切歌不能把编辑内容误存到下一首；采样率只做展示标注，不改变 Web Audio 分析采样率、音频或播放进度。信息保存只更新文字和列表，不重新播放、读取标签或更换曲绘。弹窗在舞台内部，全屏可用，离页关闭并释放编辑引用。
- 支持手动更换 JPEG / PNG / WebP / GIF 曲绘（12 MiB 以内）；当前会话内保留，离开页面释放，不上传、不开第三方服务、不承诺刷新后保存。
- 渐变对数频谱、峰值保持线和实时波形来自 Web Audio 分析，没有声音不模拟跳动。移除主画面的重复来源标签、频率刻度、专辑小字、RMS、峰值数字和文件大小；保留曲名、作者、简洁采样率徽标、播放时间及必要的失败提示。循环模式为图标，按钮保留中文无障碍名称和悬停提示。
- 播放时封面轻微浮动/旋转/随低频缩放，渐变光环转动；暂停时冻结 CSS 相位。律动默认开启，不再保留专用开关或其残留状态；仍尊重系统减少动态效果偏好。标题和操作区保持稳定。
- 纯净展示及全屏；两种模式都隐藏返回工具页入口。纯净展示保留明确退出按钮，Escape 和点击非控件的歌曲卡也可退出；退出纯净展示且非浏览器全屏时恢复返回入口。全屏按钮切换中文退出提示。浏览器全屏被拒绝时给出提示。
- 系统声音保留浏览器授权方式；不获取曲名和曲绘、不回放共享声音以避免回授。功能取决于浏览器的共享音频支持，手机可能不可用。

## 稳定性与性能

旧多层粒子/光束/冲击波绘制及重复覆盖样式已替换为一个分析画布。当前缓存对数频段索引、波形索引、渐变、尺寸及设备预算，绘制循环不重复读取布局或计算频段幂值。窄屏/低预算使用 48 根柱、像素比上限 1，普通预算使用 80 根柱，目标 60 次绘制/秒；绘制成本连续偏高时降至 30，持续恢复后才升回。减少动态效果时约 8 次/秒。频率调度保留时间余量和容差，避免浮点边界造成连绘/跳帧；这是调度策略，不是实机帧率承诺。

空白页只按需绘制，暂停后 450ms 内收束并停绘，隐藏/离页取消帧链；状态、尺寸、主题变化或恢复播放可唤醒。封面漂浮交给 CSS transform 动画，节拍缩放只低频修改封面本身，不逐帧写整页继承变量。进度保留节流并平滑显示，时间/无障碍属性只在值改变时更新。

曲绘虚化由图片加载后生成一次 160 / 256px 小画布，不创建额外 Blob URL；铺满完整可滚动舞台。不再移动/实时过滤整屏大图片。曲绘变化或缺失时更新/隐藏，离页释放画布缓冲。

参考断续网格的背景使用两个静态 SVG pattern（176px 主网格和 352px 稀疏高亮），不是为每个交点创建节点，不使用图片请求、新 Canvas、定时器或 JavaScript 逐帧生成线条。网格处于曲绘遮罩之上、内容之下，pointer-events:none 且 aria-hidden，不阻挡点击。主网格 12 秒透明度呼吸，曲绘色短线/节点 19 秒错峰浮现；主网格峰值 opacity 从 .72 降至 .4，基础墨色占比从 18% 降至 14%，稀疏高亮也降低。两组固定贝塞尔细曲线以 23/29 秒周期错峰反向起伏、渐隐，手机仅显示主曲线组。动画只改变 opacity/transform，不逐帧改变路径、布局或滤镜。播放时启用，暂停时冻结相位，后台沿用全站 songline-page-hidden 暂停规则，减少动态效果时静态显示并取消 will-change。网格覆盖整个可滚动舞台，包括手机超出一屏的内容。

曲绘加载时从已有小画布抽样 64 个位置选取色相，让光弧、频谱、播放控件跟随曲绘配色；按深浅主题限定饱和度/亮度。取色只发生一次，不参与帧循环；缺失曲绘、灰度图片或读像素失败恢复默认双色。曲绘加一层静态斜向反光，光环只保留细弧和一个轨道点，不新增粒子、星空、装饰文案或额外绘制链。

ResizeObserver 处理初始隐藏、展示模式及全屏后的画布尺寸；主题观察只更新画布配色。播放器离页清理帧链、观察器、音频上下文、共享轨道、音频和每首曲绘 URL；迟到的权限和元数据不重建已离开的播放器。

封面由各曲目拥有，切歌不撤销其他曲绘；删除曲目/替换封面才释放对应 URL。首页播放器只读取文字信息，避免无用封面分配。音乐初始界面标题为「享受你的音乐」。播放状态的左上返回箭头先重置到该初始界面，停止本地/共享声音、清空列表与信息、释放音频/曲绘 URL，取消迟到标签/图片/捕获，并回到顶部；控制器和选择按钮仍可再次使用，不执行站内换页。在初始界面，该箭头沿用全站换页调度明确返回 `/tools/`，不猜历史。播放中同步设置 data-no-page-transition 避免共享捕获阶段导航抢先离页，重置后移除此标记；修饰键/新标签点击保留链接原生行为，键盘重置把焦点移到本地音乐按钮。该入口在纯净展示或浏览器全屏时隐藏，保留模式退出方式。离页和进入纯净展示关闭歌曲浮层，不残留顶层面板。

独立场景通过 HTML / body 的 `data-page-scene="audio"` 标记隔离，直开不预加载地下图片、玻璃工具外框或无用轨迹模块。共享顶栏 DOM 隐藏而非移除，避免切回普通页面丢失已绑定控件；桌面导航清除顶部占位，手机电梯/地图解除底部 Dock。站内换页同步标记、样式和导航状态，返回后恢复普通工具页。手机全屏主容器规则必须高于公共触屏内边距规则，否则会残留 80px 顶部空隙及 14px 侧边。
