# v20.18.5 2048 新增音效

## 新增功能

2048 新增轻量音效，不引入外部音频文件，使用浏览器 Web Audio API 合成。

## 音效类型

1. 普通移动：轻微滑动 / 点击反馈
2. 合成：清脆双音，合成分值越高，音调略有变化
3. 新方块出现：很轻的 pop 反馈
4. 达成 2048：简短胜利音
5. 游戏结束：低频结束提示

## 音效开关

页面顶部新增音效按钮，状态保存在：

```text
localStorage: songline-2048-sound-enabled-v1
```

## 浏览器自动播放限制

浏览器通常不允许页面刚打开就播放音频。本版会在用户第一次点击按钮、按键或触摸棋盘时激活 AudioContext。

## 影响范围

只修改 2048 页面、2048 JS 和 CSS。不修改贪吃蛇，不新增音频资源文件。
