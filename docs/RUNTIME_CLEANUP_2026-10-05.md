# 运行时优化与旧档案代码清理（2026-10-05）

本轮保持现有外观、内容和功能，减少折叠内容的请求、搜索时的重复处理，以及移动端尺寸变化时的定时任务。不部署，不修改上传文件、文章或账号数据。

## 修改范围

- 清除档案页旧卡片布局的修补脚本、入口和 208 行专属 CSS。当前模板使用 `content-archive`，没有旧 `.posts-list`、`.posts-tag-explorer`、`.post-tag-toggle` 组件。删除的内容包含反复设置内联样式的函数、旧观察器和全局 resize 回调。
- 档案与公告的阅读次数只在条目展开时请求；手机点击、桌面 hover 和键盘聚焦均保留原有展开行为。成功读取的条目再次展开不会重复请求，失败请求仍可重试。
- 只读 GET 计数不因统计授权变动重复刷新；文章阅读页仍按授权决定是否 POST，保留去重、撤回及旧响应保护。
- 搜索按条目缓存规范化正文和标签，查询词每次输入只处理一次；条目集合在初始化时缓存，避免反复扫描 DOM。初次没有查询或标签筛选时不处理全文。保留中文分隔符、多词 AND 搜索、精确标签匹配与文章/项目切换。
- 手动搜索的工具库只在真实搜索控件存在时加载，档案自有搜索不再附带 `search-utils.js`。标签、工具和默认列表的有效搜索代码保留。
- 移动端 resize/orientationchange 连续事件分别合并为一个等待任务，保持原有延迟和页面挂入时的立即适配。

删除的是 Git 跟踪的代码和规则，可从 Git 历史恢复。没有基于一次 CSS coverage 自动删除混合样式，也没有清空媒体或运行数据。现有资源内容哈希负责更新后缓存失效。

## 对比结果

同一份公开内容的优化前后隔离 Hugo 构建；Edge 390×900 与 1440×900，深浅色偏好。测试中的 API、上传图片及外部图片全部由本地替身响应，不产生真实阅读计数。

| 页面 | 初始阅读次数请求（前→后） | JS/CSS 未压缩源码加载变化 |
| --- | ---: | ---: |
| 档案 | 28→0 | 减少约 17 KB |
| 全部公告 | 4→0 | 减少约 17 KB |
| 文章阅读 | 1→1 | 减少约 4.7 KB |

档案或公告展开第一条后只发送一次只读计数请求。桌面鼠标若停留在条目上，hover 自动展开产生的请求属于正常行为，不算折叠列表的初始加载。

其他检查页面的共享脚本增加约 85 字节，用于移动事件合并和加载条件修改；没有把减少 CPU 重复工作算成网络字节收益。上表为实际请求的唯一 JS/CSS 文件源码大小，不是 gzip/brotli 流量或公网耗时。

档案首次搜索读取 38 条正文（28 篇文章与 10 个项目），后续输入复用缓存，不再次读取正文；公告对应 4 条。搜索结果与旧逻辑一致。

36 组页面前后对比覆盖首页、档案、公告、阅读、朋友、回忆、工具大厅、随机数工具和标签页，检查的容器几何一致、无水平溢出或 JS 异常。另有 8 组档案/公告的稳定展开布局对比与截图，避开动画中间帧。占位图片不能证明真实图片的网络速度或解码性能。

手机与桌面分别连续站内切页三轮，预热后的后两轮文档数、节点数和监听数一致：

- 手机：14 个文档、2142 个节点、218 个监听。
- 桌面：14 个文档、2172 个节点、218 个监听。

这是本地浏览器测试样本，不能替代真机长期内存与公网性能测量。

## 验证与复现

- 两份离线 Hugo 构建完成，均为 178 页、229 个静态文件。
- `node --test tests/*.test.cjs` 通过；新增档案按需计数、模块加载边界、移动事件合并回归测试。
- `GOPROXY=off GOTOOLCHAIN=local go test -mod=vendor ./...` 与 `go vet -mod=vendor ./...` 通过，使用项目内测试缓存。
- `tests/privacy.browser.cjs` 通过：多尺寸与主题、授权/撤回、跨页与跨标签、过期/受限存储、首屏动画。
- `tests/runtime-optimization.browser.cjs` 完成前后对比与连续切页检查。首轮测试的桌面鼠标残留 hover 导致“关闭列表不请求”的断言失败；调整为先移走鼠标后，连续切页检查通过，无需修改运行代码。

准备两份 Hugo 输出，设置可用 Playwright 的 Node 依赖路径后运行：

```sh
BLOG_UI_BASELINE=/absolute/path/before/public \
BLOG_UI_BUILD=/absolute/path/after/public \
node tests/runtime-optimization.browser.cjs

BLOG_UI_BUILD=/absolute/path/after/public node tests/privacy.browser.cjs
```

可用 `BLOG_UI_LIFECYCLE_ONLY=1` 单独复查连续切页，或 `BLOG_UI_ARCHIVES_ONLY=1` 单独复查档案和公告。构建、截图及报告留在 Git 忽略的 `local-only/runtime-optimization/` 中；分别保存 `report.json`、`lifecycle-report.json`、`archive-report.json`，不随网站发布。
