# v20.18.5 反应测试隐藏用户名 + 管道鸟手感与管道多样化

## 反应测试

### 调整

排行榜不再显示用户名 / 游客标识。

保留逻辑：

- 登录账号仍然按账号归并，只保留最快成绩
- 游客仍然按匿名设备 ID 归并，只保留最快成绩
- 前端只显示第几名和 ms，不展示名字

## 管道鸟

### 1. 修复长按空格连续跳

旧版空格长按会触发浏览器 keydown repeat，导致小鸟一直跳。

本版新增：

- `spaceHeld`
- 忽略 `event.repeat`
- 监听 `keyup` 后才允许下一次空格起跳

### 2. 管道多样化

管道不再完全模板化。

新增随机项：

- 管道宽度
- 开口高度
- 管道颜色主题
- 管口厚度
- 横向装饰箍
- 铆钉装饰
- 高光位置

### 影响范围

只改反应测试排行榜显示和管道鸟，不动 2048、不动贪吃蛇。
