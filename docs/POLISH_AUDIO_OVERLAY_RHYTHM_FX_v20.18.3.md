# v20.18.5 音频可视化透明浮层与节奏响应优化

## 优化 1：播放界面小卡片透明度

本地播放时的几个浮层默认降低透明度：

- 左下角歌曲信息卡
- 右下角播放列表
- 右上角控制区 / 音量

hover / focus-within 时再显现到 100%，减少对可视化主体的遮挡。

## 优化 2：降低外圈和波形抢眼度

用户反馈外圈圆环和底部波形比中心更抢眼。

本版调整：

- 降低圆环频谱透明度
- 降低圆环线宽
- 降低内外圆轮廓透明度
- 降低底部 waveform 透明度
- 降低光束强度
- 中心 aura 保持存在感

## 优化 3：扩散圆跟随节奏触发

之前扩散圆主要依赖固定时间间隔，容易像固定频率动画。

本版改为 onset / bass-rise 检测：

- 记录 bassAverage
- 记录 lastBassEnergy
- 用 bass 上升沿触发 shockwave
- 每个 shockwave 有不同 life / speed
- 低频强度越高，扩散速度和粒子数量越明显

这样扩散圆会更贴近鼓点/重拍，而不是均匀频率出现。
