# 交互与布局修复（2026-10-10）

本轮只修复回忆详情关闭后的简介位置、雪人悬停提示、后台返回前台的黑屏兜底和音乐可视化操作栏。未改动持久化格式、用户内容或媒体，未部署。

## 修复与证据

- 回忆卡片的旧 `:focus-within` 规则把简介变换为 `translate(-50%,0)`，与桌面后来改成的图片右侧布局冲突。关闭原生对话框恢复图片焦点后，没有悬停时仍会套用旧变换。删除这两条旧焦点选择器，保留图片按钮的 `:focus-visible` 预览、键盘操作和关闭后焦点恢复。修改前的同一浏览器回归确实因简介横向移位而失败，修复后桌面、手机均通过。
- 雪人模板移除原生 `title` 悬停文字，同时从翻译属性列表移除 `title`；保留可访问名称以及点击、拖动和键盘功能。
- 同源正常资源下，从后台首页、账户、媒体返回前台未复现永久黑屏。故障注入定位到真实缺陷：全页返回动画直接等待资源准备，没有处理拒绝、同步异常或无限等待，也没有入场 watchdog；修改前注入准备失败后，遮罩超过 21 秒仍未释放。现在处理异常并限制资源等待，18 秒 watchdog 也覆盖未到达 `DOMContentLoaded` 的情况；清理时一起释放场景入场层，避免只清掉外层遮罩。正常加载仍等资源准备并沿用原有动画。更新后台脚本版本，前台该共享脚本 URL 加入自身内容摘要，避免继续命中旧缓存。
- 音乐页的主题和语言按钮原本是三列顶栏的第四个子元素，因此另起一行。将它们放入既有 `.av-controls`，统一高度，320px 使用较窄按钮以保持同行且不重叠；移除失用包装样式。主题按钮的普通、悬停及焦点状态均无底色、边框色和阴影，键盘焦点轮廓保留。语言按钮悬停不再上下移动。
