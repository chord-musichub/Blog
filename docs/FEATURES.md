# 功能与使用指南

公开站用于浏览与互动，创作后台用于维护内容。本地 Docker 的入口分别为 `http://127.0.0.1:8080/` 和 `/write/`；部署到其他地址时，以实例配置为准。

## 公开页面

| 页面 | 入口与用途 |
| --- | --- |
| 首页 `/` | 文章推荐、公告、文章/工具/项目/留言数量、音乐播放器与留言板 |
| 档案 `/posts/` | 普通文章和项目的统一列表，可切换模式、搜索、筛选标签和分页 |
| 文章 `/posts/<slug>/` | 封面、作者与日期、简介、正文、目录、Markdown 下载及文章留言 |
| 公告 `/tags/site-notice/` | 查看全部公告；公告详情仍使用文章阅读页 |
| 朋友 `/friends/` | 可拖动、缩放和复位的星图，进入朋友资料 |
| 回忆 `/friends/memories/` | 时间线与图片详情；手机上在时间线操作区滚动 |
| 工具 `/tools/` | 本站工具和外部工具清单，支持中英文名称与说明搜索 |

顶栏当前页面名称是小地图入口，点击展开主页面导航。地图标记当前位置；Escape、面板外点击或切页会收起它。主题按钮切换深浅色，语言按钮显示当前语言 `中` / `en`。触屏页面使用紧凑排布与独立目录抽屉，遵循系统“减少动态效果”偏好。

### 档案与公告

文章和项目每页 10 条，先对全部记录筛选，再分页。两个模式各自保存页码，修改搜索词后重置；网址中的搜索、模式和分页参数可用于刷新或返回后恢复。点击记录展开抽屉，从文章详情返回时恢复对应记录；手动收起或改变筛选、分页后不强行恢复旧抽屉。

公告由 `is_notice: true` 标识，不进入普通档案、搜索、分页或首页文章计数；仅有 `site-notice` 标签的普通文章仍按普通文章处理。旧标签网址兼容跳转到档案筛选，公告入口单独保留。

首页最多推荐五篇普通文章：保留最新一篇，其余位置随机且不重复；没有 JavaScript 时显示服务端最近五篇。项目和回忆显式保存为空列表时显示空状态，不重新补入默认内容。

### 阅读与留言

文章按“完整封面 → 作者和日期 → 标题与简介 → 阅读信息、标签和下载 → 正文”排列。详情页按保存图片的比例展示封面；后台保存过裁剪结果时，展示该结果。简介进入可见区域、场景与幕布就绪后开始打字；减少动态效果时直接显示全文。

桌面目录与手机目录抽屉共用六级标题导航。文章返回按钮随阅读吸顶，直开文章时有档案返回入口；Markdown 下载使用文章源文件。首页留言板与文章 giscus 留言分别管理，配置步骤见[文章留言](ARTICLE_COMMENTS.md)。

### 本站工具

| 类别 | 工具 |
| --- | --- |
| 阅读与效率 | Markdown 预览器、专注计时器、打字练习、随机数 |
| 音乐 | 音频可视化与播放列表 |
| 游戏 | 2048、贪吃蛇、Flappy Bird、抽卡、反应测试 |

Markdown 预览器在浏览器本地读取文件，导入后使用与文章相同的正文与目录组件。音频可视化采用独立音乐界面：播放中的返回箭头先回到音乐初始界面，再返回工具列表；主题、语言和帮助按钮在工具内提供。排行榜等功能需要运行中的 API，工具清单维护在 `assets/data/tools/`。

## 创作后台

使用实例账号登录 `/write/`。首次本地初始化生成的是管理员账号；站主与普通用户拥有不同的内容入口，不能用管理员页面推断所有投稿功能。

| 身份 | 内容与管理范围 |
| --- | --- |
| 普通用户 | 管理自己的稿件、资料和素材，可删除自己的草稿、审核中、已发布或退回文章 |
| 站主 | 创作功能、项目与回忆、站点配置，以及全站文章管理 |
| 管理员 | 审核、留言、用户、密码与全站文章管理；侧栏不显示投稿、项目或回忆入口 |

### 稿件

1. 在工作台按状态、标题搜索或分页找到稿件，继续编辑；新稿件使用投稿入口。
2. 编辑标题与 Markdown 正文，按需设置封面、摘要和标签；可预览正文、导入 Markdown、选取或上传素材。
3. 保存草稿或提交审核，公开状态取决于角色权限与审核结果。
4. 删除使用独立按钮并确认，无需先通过编辑字段的必填校验。删除已发布文章会移除公开文件和 Markdown 下载源，素材库中的媒体保留。

若删除后提示公开站构建失败，后台记录已经删除，应排查并重试构建。文章公开性和审核状态由后端校验，不能通过改 slug 绕过。

### 素材、项目与设置

素材库提供分类、搜索、上传、预览与裁剪；重命名和删除在管理操作中。项目与回忆仅站主可用，列表可展开编辑、添加或直接删除。过期页面上的项目/回忆删除请求会被拒绝，应刷新后重新操作。

账号页管理个人资料与密码。配置管理员密码以环境变量 `ADMIN_PASS` 为准，修改后重启服务；其他用户通过后台流程处理。站主的站点、外观、稿件设置各有入口，文章留言也在站点设置中配置。

## 偏好与数据

阅读统计默认为关闭；顶部隐私入口可选择“仅保留基础功能”或“允许阅读统计”，也可撤回选择。拒绝统计仍可查看已有阅读量，不影响登录、目录或工具。主题、语言和工具进度等基础功能存储继续使用；外部图片、giscus 和工具通信不由阅读统计开关控制。

语言切换只翻译界面，保留正文、作者资料、输入值、文件名和音乐元数据；详见[语言指南](LANGUAGE_SWITCH.md)。文章与媒体属于实例运行数据，备份范围见[数据边界](REPLICA_AND_PRIVACY.md)。

添加或调整功能时，可继续阅读[项目结构](PROJECT_STRUCTURE.md)、[前端架构](FRONTEND_ARCHITECTURE.md)和[测试指南](TESTING.md)。
