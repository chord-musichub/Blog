# 未展示组件的加载清理（2026-09-27）

目标：保留正式页面的视觉、内容和交互，清理已无入口的旧组件，以及在当前场景永远不可见的加载开销。不部署、不修改账号、文章或媒体数据。

## 清理与保留的边界

- 删除旧首页朋友轮播脚本、模块注册和专属 CSS。模板及动态代码已没有轮播根元素；不是删除朋友星图功能。该脚本此前已不请求，收益是发布文件和扫描项减少，不将它虚算为网络节省。
- 删除首页永久隐藏的 `scene-frame`、内部 eager/high 封面和专属样式。保留场景占位、视差入口及实际 `site-bg-layer` 背景。旧封面恰好与背景同 URL 时浏览器可能合并请求，因此不宣称固定省下一整张图片。
- 星轨通过页面模块按需加载：首页、文章区、工具大厅原本由 CSS 隐藏星轨，现在不下载脚本、不生成 SVG。由朋友页进入这些页面时移除图层并暂停 SVG；返回可见场景时恢复。标签、朋友、回忆及工具详情保留背景；减少动态效果偏好下不下载此效果。
- `galaxy.css` 仅在 `friends-list` 布局加载；回忆和朋友资料不再附带整套星图样式。站内切换仍由原有样式同步器管理加载顺序及移除。
- 保留全站导航、移动底部 Dock、文章目录、主页视差和音乐播放器，它们仍有实际入口。
- 保留朋友兼容层等混合样式：其中还有资料页、通用按钮和交互状态规则，不能因为首页未命中就整文件删除。没有做基于单次 CSS coverage 的自动全站清除。

删除的是 Git 跟踪的源文件与规则，可从 Git 历史恢复；没有删除上传文件和历史内容。

## 实测

同一份内容的前后隔离 Hugo 构建，Edge 桌面 1440×900 / 移动 390×900，浅色与深色偏好。API 和图片采用确定性替身，禁止写入真实浏览量；这里测的是加载图和布局，不是公网速度或真机耗电量。

| 页面 | 少加载的 JS/CSS 源码字节 | 请求减少 | 隐藏星轨节点 |
| --- | ---: | ---: | --- |
| 首页 | 16,041 | 1 | 桌面 22→0，移动 11→0 |
| 文章阅读 | 14,848 | 1 | 桌面 22→0，移动 11→0 |
| 工具大厅 | 14,848 | 1 | 桌面 22→0，移动 11→0 |
| 回忆 / 朋友资料 | 25,263 | 1 | 可见星轨保留 |
| 朋友星图 | 666 | 0 | 可见星轨保留 |

字节为实际请求到的唯一 JS/CSS 文件的未压缩大小，已计入新调度代码的增加；不等于 gzip/brotli 流量。24 组前后对照中检查的容器几何一致；回忆和资料页在停止装饰动画、隐藏动态星轨之后，8 组截图平均像素差均小于 0.000001/255。朋友楼层本身固定夜景，浅色偏好不会改变这一设计。

## 验证与复现

- 两份独立 Hugo 构建：178 页，静态文件 228→227。
- `node --test tests/*.test.cjs`，含按需加载条件和旧组件入口的回归约束。
- `GOPROXY=off GOTOOLCHAIN=local go test -mod=vendor ./...`。
- `tests/component-loading.browser.cjs`：24 组前后加载/几何对比，回忆及资料像素对比，连续换页加载一次、离开销毁/返回恢复、标签和工具详情背景保留、减少动态效果偏好。
- 阅读布局、朋友透镜/拖动、硬件合成、页面生命周期套件。生命周期后三次取样文档数稳定为 2，后两轮节点及监听数不增长。

准备优化前后两份 Hugo 输出（含公开内容测试样本），设置 Playwright/Sharp 的 Node 依赖路径后运行：

```sh
BLOG_UI_BASELINE=/absolute/path/before/public \
BLOG_UI_BUILD=/absolute/path/after/public \
node tests/component-loading.browser.cjs
```

构建副本和截图/JSON 留在 Git 忽略的 `local-only/component-before`、`component-after`、`component-loading` 中，不随网站发布。现有样式文件内容哈希会使更新后的资源 URL 自动失效旧缓存。
