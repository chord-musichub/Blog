# v20.18.5 贪吃蛇视觉可读性修复

## 修复点

### 1. 黑色墙不明显

旧墙体是偏灰色块，在深色棋盘上不够醒目。

本版改为：

- 黑色危险方块
- 橙色高亮边框
- 内部交叉/竖线纹理
- 轻微发光阴影

紫色脱皮墙也保留独立样式。

### 2. 临时豆连锁时大面积黄色覆盖

旧版豆子发光层直接使用十六进制颜色。  
当颜色是 `#facc15` 等亮色时，径向渐变容易变成明显实色块，遮住墙、蛇和其他豆。

本版改为：

- 所有 glow 统一转 `rgba`
- 降低透明度
- 缩小发光范围
- 粒子文字加描边、降低遮挡感

### 3. 豆子去文字化

旧版部分豆子使用“盾/慢/临/清”等文字。

本版改为颜色 + 几何图标：

- 棕色 ×：腐烂果
- 紫色菱形：脱皮果
- 金色盾形：护盾
- 绿色小表盘：缓速
- 黄色星形：星尘
- 粉色闪电：临时豆
- 黑色圆豆 + 蓝白环：清屏豆

### 4. 开始界面只展示玩法

开始界面不再写“新增/近期更新”，只展示玩法说明。
