# v20.18.5 2048 强音量版

## 调整原因

v20.14.7 音效增强后，实际听感仍然偏小。

## 本次调整

### 1. 总音量系数继续提高

```js
var SOUND_MASTER_GAIN = 9.0;
```

### 2. 峰值上限提高

```js
tone peak <= 0.55
noise peak <= 0.36
```

### 3. 基础音效 gain 提高

移动、合成、新块、胜利、失败音效的基础 gain 都提高。

### 4. 关键音效略微延长

合成音、胜利音、失败音会稍微更长一点，听感更明显。

### 5. 音效开关文案

开启时显示：

```text
音效强
```

## 影响范围

只调整 2048 音效音量和按钮状态提示。  
不修改动画、不修改排行榜、不修改贪吃蛇。
