## 阅读顺序

- 想运行网站：从本地运行开始，再看功能指南和数据备份范围。
- 想部署实例：先完成本地配置，再按服务器指南验证候选版本并上线。
- 想修改代码：先看项目结构，再按修改范围阅读服务端或前端架构，最后选择对应测试。

文档更新时保持步骤、默认值与源码一致，注明命令的运行目录和前置条件，移动文件后同步修复链接。
