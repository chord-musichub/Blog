# v20.18.5 音频可视化 UI 聚焦优化

## 优化 1：不再把浏览器原生捕获作为主流程

浏览器的 `getDisplayMedia` 权限弹窗无法由网页自定义样式，也不会单独列出网易云 / QQ 音乐这样的桌面播放器。

本版调整：

- 主流程只保留“连接本地助手”和“上传音频”
- 浏览器捕获收进“高级备用”
- 文案明确说明原生弹窗不可重绘、不会列出网易云

## 优化 2：可视化卡片圆润处理

对音频可视化页的卡片、控制按钮、状态胶囊增加统一圆角和 `clip-path:none` 保护，避免出现棱形/硬边视觉。

## 优化 3：正式开始后让出中心视觉空间

当本地助手系统声音接入、上传音频播放、或浏览器备用捕获开始后：

- 顶部大标题自动隐藏
- 引导卡片自动隐藏
- 下载说明自动隐藏
- 当前歌曲卡片变成左下角半透明小浮窗
- 控制按钮变成右下角半透明小浮窗
- hover / focus 后恢复可见

这样中心可视化不会再被大面积文字遮挡。

## 影响范围

只修改音频可视化工具。  
不修改其它工具和排行榜逻辑。
