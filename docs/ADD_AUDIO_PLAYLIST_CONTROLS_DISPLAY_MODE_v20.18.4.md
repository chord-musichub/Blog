# v20.18.5 音频可视化播放列表控制与纯净展示模式

## 新增 1：播放列表收展

本地音乐列表新增“收起 / 展开”按钮：

- 收起后只保留列表标题与控制按钮
- 展开后显示歌曲列表
- 状态通过 `.is-playlist-collapsed` 控制

## 新增 2：列表内移出

每首歌右侧新增“移出”：

- 可把单首歌踢出当前播放列表
- 移出当前播放歌曲时自动切到下一首
- 移出最后一首时停止播放并回到等待状态

## 新增 3：播放模式切换

新增播放模式按钮，循环切换：

```text
列表循环 → 单曲循环 → 随机播放
```

播放结束时按当前模式决定下一首。
手动“上一首 / 下一首”仍按正常切歌逻辑执行。

## 新增 4：全隐藏 / 纯净展示模式

右上角新增“全隐藏”按钮：

- 隐藏右上角控制区
- 隐藏右下角播放列表
- 隐藏提示和顶部信息
- 隐藏返回键
- 只保留左下角歌曲信息卡
- 歌曲信息卡常亮高亮

退出方式：

- 点击歌曲信息卡
- 按 Esc

## 优化 5：小浮层透明度

播放时小浮层默认更透明：

- 歌曲信息卡
- 播放列表
- 右上角控制区

hover / focus 时完整显示。
