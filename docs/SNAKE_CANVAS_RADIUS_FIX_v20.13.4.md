# v20.18.5 贪吃蛇 Canvas 大面积颜色覆盖修复

## 问题

贪吃蛇在临时豆连锁或特殊豆出现时，仍可能出现大面积颜色覆盖，导致墙、蛇、其他豆看不清。

## 根因

v20.13.3 中为了让特殊豆变圆，Canvas 绘制时使用了类似：

```js
roundedRect(..., 999)
```

这种写法在 CSS 里常见，例如 `border-radius: 999px`。  
但 Canvas 的 `arcTo` 半径如果远大于矩形尺寸，可能会生成超出小格子的巨大弧线，导致填充区域异常扩大。

## 本次修复

### 1. 修正 roundedRect

圆角半径现在强制限制在格子尺寸内：

```js
r = Math.max(0, Math.min(Number(r) || 0, Math.abs(w) / 2, Math.abs(h) / 2));
```

并且补齐 `lineTo`，避免路径异常。

### 2. 收掉豆子大面积 glow

不再使用大半径径向渐变填充。  
特殊豆只保留小范围外圈，不会覆盖棋盘。

### 3. 降低墙体阴影范围

墙保留危险边框，但减少 shadow smear，避免在小格子里糊成色块。

## 预期效果

- 临时豆连锁时不会再出现大面积黄色/粉色覆盖
- 墙、蛇和其他豆始终可见
- 特殊豆仍能靠颜色和图标区分
