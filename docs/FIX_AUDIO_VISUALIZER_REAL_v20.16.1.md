# v20.18.5 音频可视化真实修复

## 修复 1：彻底移除浏览器原生捕获主流程

浏览器的 `getDisplayMedia` 权限弹窗属于浏览器安全 UI，网页不能重绘它的样式，也不能删掉里面的系统选项。

因此本版不再把它作为音频可视化入口：

- 页面不再显示“浏览器捕获”按钮
- 主流程只保留：
  - 连接本地助手
  - 上传音频
- 系统声音统一走 SonglineMusicBridge 的 WASAPI Loopback

## 修复 2：本地助手源码编译错误

v20.16.0 的 `Program.cs` 中有一处重复变量：

```csharp
double sample = 0;
double sample = 0;
```

这会导致本地助手无法编译。v20.18.5 已修复。

## 修复 3：中心可视化无遮挡

连接本地助手后立即进入观赏模式：

- 顶部标题隐藏
- 来源卡片隐藏
- 说明卡片隐藏
- 歌曲信息缩到左下角半透明浮窗
- 控制按钮缩到右下角半透明浮窗

中心区域留给 Canvas 可视化。

## 修复 4：圆角/棱形边框

对音频可视化的卡片追加高优先级圆角与 `clip-path:none`、`mask:none` 保护，避免出现棱形边框。

## 注意

部署后需要重新下载并重新构建 `SonglineMusicBridge-v20.18.5-source.zip`。
