# v20.18.5 2048 排行榜 + 工具页标题透明风格统一

## 新增 2048 前三名排行榜

2048 现在和贪吃蛇一样有服务器前三名成绩。

### 后端新增 API

- `/api/tools/2048-scores`
- `/write/api/tools/2048-scores`
- `/static/api/2048-scores`
- `/api/2048-scores`

数据文件：

```text
data/2048_scores.json
```

### 提交时机

游戏结束后自动提交当前分数。  
前端也会缓存最近一次 top3，接口失败时优先显示本地缓存。

## 工具子页标题透明风格统一

2048 的标题区是比较轻的透明标题，不是厚卡片。  
本版把其他工具子页的标题同步成类似风格：

- Markdown 预览器
- 随机数生成器
- 贪吃蛇
- 抽卡模拟器

工具首页 `/tools/` 保持原本现代工具首页样式，不受影响。
