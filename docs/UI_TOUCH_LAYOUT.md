# 展示页交互与触屏布局

## 推荐

首页保留最多五个轮播位置。构建时输出文章池元数据，每次首页初始化保留最新一篇，其他四篇不放回随机抽取；不包含站点公告。不新增请求接口，不记录浏览历史。脚本不可用时保留服务端最近五篇。图片展示框统一 16:9，不修改原始文件。

## 顶栏、档案与首页方格

桌面和手机共用 60px 透明玻璃顶栏，深浅主题同步；图标保持位于栏内。档案中心卡片取消左侧地图轨道偏移，水平居中，手机保持现有边距。首页保留四格结构：文章、工具、项目数量和留言数量。项目入口直接打开档案的项目模式；留言入口由旧底部文字移入方格，沿用现有面板、投稿、返回焦点和留言预览，不增加请求。

项目数与档案列表读取同一份运行时数据，清空后显示 0 和空列表，只有数据键缺失时才使用构建种子。回忆页遵循同样规则，删掉最后一条回忆后显示空状态。`home-empty-archives.browser.cjs` 通过 `BLOG_EMPTY_ARCHIVES_BUILD` 指定保留种子且运行时项目、回忆均为空数组的隔离构建，验证桌面和手机上的空状态。`home-header-layout.browser.cjs` 通过 `BLOG_HOME_LAYOUT_BUILD` 指定隔离 Hugo 源目录，检查 1920、1440、1024、820、390px 的深浅主题、直开/刷新/AJAX、音频返回、卡片几何居中及留言键盘/提交/计数。测量与截图保存在 `local-only/header-home-2026-10-09/`。本轮 177 项前端单元测试通过。

## 搜索与导航

档案仅收录普通文章和项目，`is_notice: true` 的公告保留在首页公告区与“全部公告”，不进入档案记录、搜索词、分页或首页文章计数。未设置公告标记或显式为 `false` 的普通文章仍正常收录，不能仅凭 `site-notice` 标签判断。`notice-isolation.browser.cjs` 使用 `BLOG_NOTICE_BUILD` 指定含 17 篇普通文章、13 篇公告和草稿公告的隔离 Hugo 源目录，另以 `BLOG_NOTICE_ONLY_BUILD` 指定仅公告构建，验证桌面/手机、搜索、分页、首页计数、公告详情与历史返回。

档案搜索词由全部普通文章标签及项目技术栈生成，不再截取前十项。文章、项目和搜索占三个明确入口，展开词条区支持换行和独立滚动。

小地图根据完整 pointer 手势判断点击。只有在同一导航目标上按下并在移动阈值内松开（鼠标 3 CSS 像素、触屏 8 CSS 像素）才会触发导航；跨出目标、拖拽或 pointercancel 后产生的 click 会被拦截，键盘激活保留。地图收起时不参与正文命中，主动展开后面板接收自己的点击。

公开站主页面入口仅保留小地图，电梯栏、方向把手和隐形点击感应带已删除。地图独立初始化，桌面和手机共用顶栏左侧的当前页面文字入口，原 Blog 字样与角落入口已删除。深色浅青、浅色暖金的文字、细边框及下拉箭头提示可点击；点击展开原五区域空间布局，名称常显、当前位置高亮。入口名称在直开、刷新、AJAX、历史遍历后同步，文章显示“档案”、公告显示“公告”、工具子页显示“工具”。Escape、面板外点击、焦点移出及切页收起地图，Escape 从地图区域交还焦点到入口；收起区域不进入键盘焦点序列。移除了旧靠近放大测量、底层点击转发和移动底部 Dock 搬移。`site-map-navigation.browser.cjs` 使用 `BLOG_MAP_BUILD` 指定隔离 Hugo 源目录（其中包含 `public/`），覆盖全部地图入口、历史遍历、触屏、拖动取消、音频场景返回及桌面/手机布局切换。

朋友页星图在真实节点和 SVG 连线之上使用同一坐标投影实现中心放大镜：中心头像轻微放大，边缘内容通过遮罩和 `backdrop-filter` 柔焦。拖动/缩放时仅更新节点与连线的投影，柔焦遮罩的中心和半径保持不变，减少全屏模糊纹理的重建。不会克隆图片或额外发起资源请求，系统减少动态效果时会降低动画强度。

透镜中心固定于画布中心，不随每帧手势速度摆动，同一位置的头像和线端在拖动、停住、松手时使用相同投影。拖动、惯性和缩放过程中暂停悬停高亮切换，保留已选中状态。滚轮与缩放/复位按钮使用 260ms ease-out 插值，头像与 SVG 线端在同一帧更新；连续输入从当前帧接续，拖动、失焦或离开页面会取消未完成的缩放。启用系统减少动态效果时直接到达目标。

v22.15 合成兼容调整：只对整个星图工作区保留 `will-change:transform`，不再为每个头像或柔焦容器强制增加 3D 合成层、背面剔除。运动层使用布局/样式隔离，固定柔焦层使用独立绘制边界；不裁切运动层的边缘头像与光晕，不修改模糊半径、遮罩、阴影或缩放缓动。这是兼容性调整，不代表已经排除所有 GPU/驱动上的消失帧。

`article-navigation-priority.browser.cjs` 使用同一隔离构建，验证桌面和手机收起的地图不拦截正文按钮、链接、原生折叠标题、标签和禁用控件；主动展开的地图点击不再转发到底层控件。

## 触屏布局边界

`static/css/touch-layout.css` 是公开站紧凑布局的最终入口，位于页面样式末尾。宽度不超过 760px，或不超过 980px 的无悬浮触屏设备使用该布局；较宽桌面保留原构图。

- 顶部保留图标、当前页面地图入口与主题/投稿入口；手机与桌面共用地图位置。
- 首页直接展示信息终端，推荐、统计、音乐操作纵向组织；雪人继续保留。
- 工具列表单列；图标与方向提示没有额外填充、阴影或毛玻璃底。
- 朋友与回忆操作区保留页头安全间距；回忆页的外层不滚动，同日图片过多时在时间线操作区内纵向滚动。
- 文章目录使用独立抽屉，阅读浮动按钮保留触屏操作留白；触屏平板使用同一规则。

顶栏当前页面入口采用完整填色矩形，常态无边框；最终调整为 44px 高、4px 微圆角，与 Logo 垂直居中且相距 16px。深色使用低饱和灰蓝，浅色使用暖灰与深色文字；hover 和展开状态轻微提亮，键盘操作保留焦点轮廓。地图的空间布局与交互保持原样。1440×900、390×900、320×390 的深浅主题检查覆盖尺寸、间距、文字对比度、hover、地图边界和切页；最终截图与测量位于 `local-only/header-map-balance-2026-10-09/`。

## 首页雪人弹簧

雪人木杆改为固定底座的六圈金属 SVG 弹簧；空闲时以约 −13° 到 +14° 摆动，并同步伸缩线圈。拖动最大约 46°，线圈沿弯曲轴线变形；松手使用带阻尼的回弹，可随时重新抓住。点击、Enter 或空格触发弹跳。手机仅摆件自身禁用触摸滚动，其他区域继续正常滚动；减少动态效果时停用空闲和回弹动画，只保留小幅直接拖动反馈。

空闲运动由 CSS 驱动，交互最多使用一条有限帧链。离场、隐藏或图片失败停止任务，缓存恢复后保持可用；不改变原雪人图片及 `desktop_pet.image` 配置。`desktop-pet-spring.browser.cjs` 用 `BLOG_PET_BUILD` 指定隔离 Hugo 源目录，七组检查覆盖桌面/手机、深浅主题、减少动态效果、强回弹、连续抓取、取消、触摸捕获、键盘和图片失败；连续切页 10 轮没有增加全局监听，交互同时最多一条帧任务。177 项单元测试通过，测量及截图位于 `local-only/pet-spring-2026-10-09/`。

`cover-cropper.browser.cjs` 使用独立页面与合成图片验证裁剪滑块重绘、缩放中心、拖动取消和重新打开时的状态重置，不读取或修改真实媒体库。

`reader-layout.browser.cjs` 验证明暗主题、手机/平板/桌面/短屏、55 个标题的内部滚动、目录收起与锚点跳转，以及极宽/极高封面不撑大头部。测试拦截阅读计数请求；`BLOG_READER_BUILD=/path/to/public` 可指定隔离构建产物的文章 HTML，配合本地源码资源验证尚未部署的模板。

## 同日回忆与媒体分类

同日回忆共享日期列的高度基准，以图片高度加留白竖向排列，不再混用单张卡片的 `nth-child` 错位。时间线根据当前断点的图片和标题边界计算高度；超出屏幕时保留纵向滚动，横向拖动仍切换日期。`memories-stack.browser.cjs` 使用合成数据验证每日期 3/5 张图片、短屏、手机、平板以及释放拖动。

已上传素材可在“管理 → 修改分类”中调整分组，原图路径与字节保持不变。分类保存到运行时 `DATA_DIR/media-categories/<owner>.json`（备份时应包含整个运行时数据目录），不进入公开媒体目录。记录绑定文件大小和修改时间，避免同名重新上传继承旧分类；重命名与裁剪副本继承有效分类。

裁剪依据原图路径匹配登录者的个人素材库；站主还可裁剪站点素材库的图片，不再把编辑页的上传目标库误当作原图归属。其他用户的图片仍拒绝操作。分类修改只允许在当前管理的库内进行。
