# 第三方图片与页面资源加载优化

本轮目标是在不改变原有内容、布局、外链地址和原图入口的前提下，降低无必要的并发请求，改善慢网、断网恢复与无刷新切页。未部署网站、未修改用户数据、未增加服务器图片代理或新的第三方 CDN。

## 改动

- 正文 Markdown 图片在 Hugo 初始 HTML 和浏览器渲染器中都默认使用原生懒加载、异步解码。渲染器里的原始 HTML 图片也补充默认值，但保留作者明确指定的 `loading`、`decoding`、尺寸等属性。不会改写带签名参数的外链 URL，也不会把正文原图替换成低分辨率预览。
- 文章从初始 HTML 更新为 Markdown 渲染结果时，通过惰性解析和属性匹配复用相同图片元素；避免已显示的第三方图片再次下载和解码。属性变化或 `<picture>` 图片不强行复用。复用元素不移入模板的惰性文档，避免浏览器因文档归属变化重新请求。
- 工具页的第三方图标在距视口 320px 内才设置真实 `src`，不再依赖浏览器较宽的原生预加载范围。尺寸仍为 36×36；搜索和滚动会触发加载；无 JavaScript 时使用 `noscript` 保留原地址。本站图标仍使用上一轮的本地派生预览。
- 图片更换来源时取消旧的监听和等待状态，旧回调不能覆盖新来源或重复解码。切页时清理未完成的监听、定时器及观察目标；旧页面的 `prepare` 结果不会重新注册观察或覆盖新页面的状态。
- 网络恢复事件发生时，仅对可见/邻近的失败图片重试，每个元素、同一来源最多一次；重复事件不会无限重试。仍在网络请求中的超时图片不另起并行重试。这里是有限恢复，不是失败图片永久轮询。
- 图片观察超过 30 秒会结束等待，但保留迟到响应的恢复路径；加载成功后既恢复显示，也更新可查询的就绪结果。懒背景图同样可迟到恢复，且只更新仍连接在页面、来源仍匹配的元素。页面恢复也能重新准备已取消的背景。
- 图片揭幕等待预算仍为 1.2 秒，不把第三方长时间不可达变成整页锁定。该预算不是下载超时；资源可继续在后台加载。取消监听也不等于能强制中止浏览器已经开始的所有网络请求。
- 星图脚本仅在星图页面预加载，回忆和朋友资料页不再加载无用的星图脚本；直开与动态模块使用一致的版本 URL。通用文章卡片的本地背景缩略图接入现有派生预览，原文件不变。

## 实测证据

本机 Edge/Chromium；第三方域名使用可控响应模拟，不将远端服务的偶然快慢当作优化收益。工具图标对照使用同一份构建 HTML、样式及图片响应，只比较原生 `src + loading=lazy` 与按邻近区域设置 `src`。

| 场景 | 对照 | 修改后 |
| --- | ---: | ---: |
| 20 张远处正文图片，滚动前请求数 | 20 | 0 |
| 27 个第三方工具图标，1440px 首屏请求数 | 13 | 6 |
| 同一集合，390px 首屏请求数 | 9 | 5 |
| 同一图片快速切换来源的解码调用次数 | 3 | 1 |

这些是特定布局和浏览器下的请求/工作量，不代表总流量同比下降，也不是打开速度的倍数承诺。正文滚动到图片后仍会加载原图；工具图标全部可通过滚动或搜索取得。

其他验证：

- 已显示的相同外链图片在文章重新渲染后仍是同一个元素；`Cache-Control: no-store` 测试响应仅请求一次。
- 失败后模拟网络恢复：初始请求一次、恢复重试一次；重复恢复事件不增加请求。
- 超过观察期限的图片和背景、快速换源、页面离开、过期就绪任务、页面恢复均有回归用例。
- 真实页面模拟头像延迟 5 秒：朋友页约 2.3 秒解锁，报告仍有 1 个待完成资源，之后头像正常显示；没有将提前解锁误报成资源全部完成。该时间包含页面动画，是本机单次测量。
- GPU 开启时，朋友页在 1440px/390px 和深浅主题下录制拖动、松手、缩放；参考样式的几何尺寸一致，平均像素差约 0.106–0.312/255，动态场景不承诺逐像素相同。
- 三轮文章→工具→回忆→首页→朋友切换后，桌面与手机文档数均为 2/2/2；后两轮节点和监听数不再增加。验证的是这条路线的稳定性，不是应用永远不占用额外内存的证明。

原始结果与截图位于被忽略的 `local-only/external-resources/`；切页记录位于 `local-only/page-lifecycle/`，GPU 截图及录像位于 `local-only/galaxy-compositing/`。

## 复现与回归

```sh
node --test tests/*.test.cjs
go test ./...

# 需要可用的 Playwright、Edge；完全模拟第三方图片，不要求运行网站。
node tests/external-resources.browser.cjs

# 可选：用 HEAD 中的旧源码作为对照，记录预期失败，不作为通过门槛。
RESOURCE_AUDIT_BASELINE=1 node tests/external-resources.browser.cjs

# 指向最新 Hugo 输出及本地测试站点。构建页、脚本由测试覆盖，
# 媒体等剩余运行时资源使用该本地站点；阅读计数被拦截。
BLOG_UI_BUILD=/absolute/path/to/fresh/public \
BLOG_TEST_URL=http://127.0.0.1:8080 node tests/third-party-pages.browser.cjs

# 慢资源基础用例；额外指定 BLOG_TEST_URL 可测试真实页面切换。
node tests/resource-readiness.browser.cjs
```

本轮验证使用隔离 Hugo 构建（178 页、228 个静态文件），未替换正在运行的网站。阅读布局/目录、朋友页视觉与 GPU 合成、连续切页、手机公开页面和工具的横竖屏布局另由现有浏览器套件检查。上述浏览器测试需要其指向的站点或资源覆盖确实使用最新模板和源码；不能仅以旧站点通过测试证明新代码正确。

## 边界与发布

- 没有替第三方服务器承诺可用性：DNS、跨境网络、限流、防盗链、过期签名或服务关闭仍可能导致失败。客户端懒加载不能压缩第三方原图，也不能覆盖对方的 HTTP 缓存规则。
- 不引入通用后端抓图接口，避免增加 SSRF、带宽滥用和缓存隐私风险。若后续需要长期镜像或托管第三方图片，需要另行确定授权、允许的来源和缓存策略。
- 未在真实 Safari/iOS、低端 Android 和移动弱网设备上测试；本机移动视口不等同于真机。上线后仍应观察实际 LCP、INP、CLS、资源失败率。
- 本轮没有新增 Go 依赖。后续构建修复已将现有依赖随源码保存，见 [可重复的 Go 依赖构建](BUILD_DEPENDENCIES.md)；本机 Docker 镜像代理仍与 Go 依赖构建是不同环节。
- 代码尚未自动提交、推送或部署。发布需要完整带上模板、公开脚本与 `web/static` 中的共享加载器；验证时刷新已打开的旧页面，避免混用旧运行时与新模板。

## 工具图标不可达的兜底

第三方工具不再调用 Google favicon。`assets/data/tools/external.json` 保存官网声明的图标地址或其官方静态资源域名，仍由浏览器网址直连，不做本地托管或后端代理。2026-10-06 核对时，25 个工具对应的地址返回图片；武科大 CSDIY 未声明图标且默认地址 404，东方狗站点返回验证页面，两处保留直接地址与首字兜底，不把 HTTP 200 的 HTML 验证页面误当作成功图片。外部网站仍可能限流、拦截、变更地址或不可达，不能承诺每个客户端始终可用。

懒加载与首字兜底复用共享图片加载器的就绪、取消和离页清理契约，不增加全局监听、轮询或无界重试。超时但仍在下载的图片保持原迟到恢复路径，不另开并行请求。`tests/tool-icons.browser.cjs` 使用离线构建覆盖桌面/手机、深浅主题、正常/不可达以及滚动、搜索、重复观察和 AJAX 重入，并断言不存在 Google 请求。Playwright 自动拦截所有恰好以 `/favicon.ico` 结尾的请求，测试响应中的图标地址使用固定查询参数避开这条规则，生产地址不受影响。
