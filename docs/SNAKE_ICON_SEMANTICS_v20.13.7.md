# v20.18.5 贪吃蛇图标语义修正

## 背景

v20.13.6 中：

- 惩罚豆使用红色 X
- 普通危险墙使用一般的内部纹理

视觉上会有一点反直觉：  
红色 X 更像“禁止碰撞”的障碍，而不是可吃的豆子。

## 本次调整

### 1. 惩罚豆改为警示图标

惩罚豆不再使用红色 X，改成：

- 警示三角形
- 中间感叹号样式

这样它更像“吃了会出事的特殊豆”。

### 2. 普通危险墙改为红色 X

普通黑墙内部改成红色 X：

- 一眼看出是阻挡物
- 更符合“不能撞”的直觉

### 3. 紫色脱皮墙保留独立样式

紫色脱皮墙仍然保留菱形内部图案，避免和普通墙混淆。
