# v20.18.5 调大 2048 音效音量

## 调整原因

v20.14.6 新增了 2048 音效，但实际听感偏小。

## 本次调整

新增总音量系数：

```js
var SOUND_MASTER_GAIN = 3.0;
```

并把 Web Audio API 中的 tone / noise 音效整体增益提高。

## 保护

为了避免耳机或外放突然过响，本版仍设置了峰值上限：

```js
tone peak <= 0.16
noise peak <= 0.11
```

## 影响范围

只调整 2048 音效音量。  
不改 2048 动画、不改排行榜、不改贪吃蛇。
