# v20.18.5 音频可视化返回键接管停止逻辑

## 修复 1：删除右上角停止按钮

右上角控制区移除：

```html
<button data-av-stop>停止</button>
```

保留：

- 打开新文件
- 全屏显示
- 音量控制

## 修复 2：返回键外观保持原样

上一版把返回键做成了胶囊按钮并加了“返回”文字，不符合预期。  
本版恢复为小圆形返回键样式。

## 修复 3：停止逻辑移植到返回键

点击返回键时，会先执行：

```js
stopAll()
```

然后让原本的返回链接继续跳转。  
这样返回键视觉不变，但功能上会顺手停止本地音频 / 浏览器音频流。
