# v20.18.5 修复 2048 音效实际响度不足

## 问题

v20.14.8 中虽然加入了 `SOUND_MASTER_GAIN = 9.0`，但 tone / noise helper 里仍然使用原本偏小的 gain 值，导致实际听感提升不明显。

## 本次修复

### 1. 真正应用总音量系数

`playTone()` 和 `playNoise()` 现在都会使用：

```js
SOUND_MASTER_GAIN
```

### 2. 对齐贪吃蛇的响度区间

贪吃蛇音效常见峰值约在 `0.12 ~ 0.18`。本版把 2048 的移动、合成、新块、胜利、失败音效也拉到这个听感范围。

### 3. 保留峰值保护

```js
tone peak <= 0.34
noise peak <= 0.22
```

## 影响范围

只调整 2048 音效响度。不改 2048 动画、不改排行榜、不改贪吃蛇。
