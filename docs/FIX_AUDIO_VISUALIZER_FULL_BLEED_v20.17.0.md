# v20.18.5 音频可视化默认界面铺满屏幕

## 问题

用户反馈默认界面没有占满全部屏幕，而是只显示为导航栏下方居中的一块舞台区域。

## 修复

本版把音频可视化工具改为 full-bleed 页面：

- `audio-visualizer-page` 宽度改为 `100vw`
- `.av-stage` 宽度改为 `100vw`
- `.av-stage` 高度改为 `calc(100svh - nav height)`
- 移除舞台默认圆角 / 边框 / margin
- 背景与 canvas 铺满导航栏下方整块区域
- 来源卡片按全屏宽度重新定位
- live 状态也保持铺满导航栏下方区域

## 说明

站点导航栏仍保留。  
音频可视化区域会铺满导航栏下方剩余屏幕，不再是中间一块“大卡片”。
