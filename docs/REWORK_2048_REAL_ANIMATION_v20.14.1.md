# v20.18.5 2048 真滑动与合成动画重做

## 修复点

### 1. 移除重复返回键

`layouts/tools/2048.html` 里原本额外写了一个页面内返回按钮。  
站点工具子页已经有统一返回键，所以本版删除额外按钮，只保留统一返回键。

### 2. 重做 2048 渲染方式

旧版每次移动后直接重建 4×4 DOM，所以看起来像瞬移。  
本版改成：

- 背景格子层：`game-2048-cells`
- 数字块层：`game-2048-tile-layer`
- 每个数字块有独立 id
- 每个数字块用 absolute + transform 定位

### 3. 真滑动动画

移动时保留旧数字块 DOM，只更新 transform。  
浏览器会执行：

```css
transition: transform 210ms cubic-bezier(.2,.86,.22,1);
```

所以数字块会真实滑到目标格。

### 4. 合成动画

两个数字块滑到一起后，生成新的合成块。  
合成块带：

```css
.game-2048-tile.is-merged
```

会有轻微 pop 动画。

### 5. 新数字块出现动画

新生成的 2/4 带：

```css
.game-2048-tile.is-new
```

会有 appear 动画。

## 影响范围

只改 2048 页面、2048 JS 和 CSS，不动贪吃蛇。
