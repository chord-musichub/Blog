# 全站操作流畅性（2026-10-07）

本轮保持现有主题、布局、转场节奏和朋友页行星轨迹。重点修复导航、阅读定位、档案/公告搜索和键盘操作；未部署、未改依赖、未删除用户内容。没有新增页面 HTML 缓存或推测性预取，避免展示过期文章或增加第三方请求。

## 具体变化

- 转场锁定时，同源普通链接仍被接管，不再落入浏览器整页刷新。连续请求保留最后一个排队目的地，复用当前转场控制器；被后续操作替代的目的地不下载。同一在途目的地不会重复排队；排队 API 的 Promise 在处理后结束。
- 只有实际启动导航时才保存当前历史位置。浏览器 Back/Forward 优先于待执行链接；请求或样式加载期间若已经遍历历史，不再 pushState 覆盖历史游标。加载失败继续使用原生文档兜底，并清除待执行跳转。
- 转场定位、历史恢复及深链接即时跳转使用 `instant`；原来的 `auto` 会继承桌面全局平滑滚动，让幕布揭开时仍在移动。用户点击目录、上下按钮仍平滑滚动。
- 新文章的 `#标题` 链接等待有界的 Markdown 渲染完成，在资源准备前定位、准备后校正。文章末尾允许按实际文档长度钳制滚动。Back/Forward 以保存的滚动位置为准，而不是旧 hash。
- Markdown 初始化记录本次滚动归属；迟到的远程正文不能在 AJAX 转场结束后重新跳至 hash。只有原生文档进入保留原有 hash 定位定时器。
- 档案/公告搜索支持中文 composition；选字时不反复过滤或修改 URL，输入法 Escape 不再清空搜索、丢失焦点。选字后提交最终文本；同一事件轮次合并重复 input，不引入防抖等待；被替换的 DOM 不提交迟到搜索。状态文字未改变时不重写节点。
- 已锁定的档案抽屉不会因子链接取得焦点或重新 hover 而失去锁定。项目详情可通过 Tab/Enter/Space 打开，父容器不拦截内部原生链接、控件和带修饰键的点击。

## 工作量与回归

离线同内容、同事件序列对照（手机 390px、桌面 1440px）：

| 指标 | 原版本 | 本轮 |
| --- | ---: | ---: |
| 四个 IME 候选输入及选字期间 Escape 导致的 history 更新 | 5 | 0 |
| 该完整输入序列的 history 更新 | 6 | 1 |
| 本轮同一事件轮次 20 个 input 的 history 更新 | 未在该夹具对照 | 1 |

原版本会清空候选文本并失焦；本轮候选文本和焦点保留。连续跳转夹具保持同一 `performance.timeOrigin`，被替代的公告目的地没有文档请求，前进后退无多余历史项。人为延迟 Markdown 下载 1.8 秒后，历史仍恢复并保持原先的 250px 位置；加载中返回也不生成幽灵历史项。

三轮全站切页后的节点/监听保持稳定：手机 824/192，桌面 854/192。本轮增加了导航保护代码，入口源码约增加 2.6–3.8KB；这是减少重复操作和定位竞争，不是压缩文件体积，也不是公网延迟或真实手机 FPS 保证。

验证通过：

- 离线 Hugo 构建 178 页、Go vendor 测试、23 个 Node 单元测试文件。
- `ux-fluidity.test.cjs`：输入合并、composition/脱离 DOM 保护、锁定链接策略、即时/平滑阅读定位。
- `article-source.test.cjs`：迟到正文滚动所有权、正文超时及内嵌回退。
- `ux-fluidity.browser.cjs`：手机/桌面正常动画下输入法、搜索事件合并、抽屉锁定、项目子链接键盘行为、连续点击、历史遍历优先、深链接和迟到正文。
- `cleanup-performance.browser.cjs`：18 路由 × 手机/桌面 × 深浅主题，72 组布局/样式/截图对照；几何与样式一致，像素平均差低于 0.02/255。
- `runtime-optimization.browser.cjs` 生命周期模式：三轮首页、档案、公告、阅读、工具、朋友与回忆切换，检查组件、CSS 恢复、GC 后节点和监听。

浏览器请求全部由本地构建、图片与 API 夹具响应，不请求线上账号或写入线上 API。真实手机 Edge 工具栏/GPU 和实际第三方网络仍需设备验证。构建、截图与专项报告保存在忽略目录 `local-only/ux-fluidity/`，历史/生命周期报告沿用各自测试目录。
