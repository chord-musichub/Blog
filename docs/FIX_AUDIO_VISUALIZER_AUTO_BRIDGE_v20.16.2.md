# v20.18.5 音频可视化自动桥接与界面修复

## 重点说明

网页不能重绘浏览器的系统权限弹窗。  
因此本版不再使用浏览器捕获弹窗，系统声音只走本地助手。

## 修复 1：打开页面自动读取系统声音

页面加载后会立即尝试连接：

```text
http://127.0.0.1:23333/status
http://127.0.0.1:23333/audio
```

如果本地助手已经运行，网页会自动接入系统输出声音并进入可视化，不需要再点击浏览器捕获。

## 修复 2：初始不显示歌曲信息卡片

刚进入页面时不显示当前歌曲信息。  
只有上传音频或本地助手读取到真实歌曲标题后，左下角才显示迷你歌曲卡片。

## 修复 3：中心可视化无遮挡

系统声音接入后：

- 顶部标题隐藏
- 来源卡片隐藏
- 说明卡片隐藏
- 控制按钮缩到右下角
- 中心区域只留给 Canvas 可视化

## 修复 4：最外边框圆滑处理

音频可视化页面外层 `.av-stage` 增加：

- 大圆角
- overflow hidden
- round clip-path
- 内描边

## 修复 5：本地助手一键包

新增下载：

```text
/downloads/SonglineMusicBridge-v20.18.5-oneclick.zip
```

包内包含：

- Program.cs
- build.ps1
- Run-Bridge.ps1
- Run-Bridge.cmd
- csproj

推荐 Windows 上双击 `Run-Bridge.cmd`。
