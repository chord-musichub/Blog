# Cookie / 存储偏好与运行开销优化（2026-09-28）

范围：保留页面原有布局与功能，增加公共网站的隐私偏好入口，不部署、不重启服务、不改用户内容或真实阅读计数。此实现是实际行为说明与功能控制，不是法律合规认证。

## 存储与请求审查

- 服务端 `session` Cookie 用于登录，现有设置包含 HttpOnly、SameSite=Lax；登录退出流程未修改。
- 功能性浏览器存储用于主题、目录展开状态、首页开场状态、页面过场、音乐位置、工具进度/音量、游戏记录和排行榜相关标识/缓存。它们不被“拒绝统计”误删。
- 可选项是文章阅读统计：`/api/views` 的 GET 读取已有汇总，POST 增加次数；`songline-viewed:*` 会话标记用于避免当前会话重复计数。未选择、拒绝、过期或隐私脚本加载失败时，前端只发 GET。
- 没有发现专门的广告追踪脚本。外部图片、头像和图标仍是内容请求，可能向来源暴露 IP 等网络信息；弹窗明确说明它们不受阅读统计选项控制。不承诺清除第三方 Cookie，也不承诺屏蔽全部第三方网络请求。
- 排行榜等工具通信、必要服务端日志不纳入文章统计开关。第三方内容或新统计服务接入时，应重新审查并更新说明/偏好版本。

## 弹窗与行为

- 顶部通栏的非模态玻璃风格抽屉：桌面说明与按钮分列，手机纵向排列；支持深浅主题、短横屏内部滚动、安全区。展开 280ms、收起 200ms，仅变换与透明度动画；减少动态效果偏好下直接切换。不锁背景、不自动抢焦点、不额外引入第三方依赖。
- “仅保留基础功能”和“允许阅读统计”同等显示。用途详情可展开；顶部盾牌按钮可随时重新打开，键盘焦点移入面板，选择后返回入口。独立“收起”按钮和 Escape 只执行收起动画，不保存或修改许可；尚未选择时仍默认关闭统计，下次完整访问仍会提示。
- 使用本地 `songline-privacy-v1` 保存版本、统计布尔值和 180 天有效期。不使用访客身份信息，也不为弹窗新增 HTTP Cookie。浏览器禁用存储时保留当前文档的内存选择，并在详情中说明。
- 站内 AJAX 切换只保留一个弹窗与一组监听；重新加载可恢复选择。支持跨标签页更新、删除偏好后的重新提示，以及页面重新显示/切换时检查过期。
- 允许后当前文章重新初始化计数；撤回后新扫描不再 POST，并清除本标签页的统计会话标记。发送前的微任务会再次核对许可；已经发出的请求无法撤销，不会在撤回后重新写统计标记，也不会删除过去的汇总计数。
- 拒绝统计不隐藏已有浏览量、不影响文章目录、返回、登录或工具操作。API 本身仍保留原有 GET/POST 接口；偏好控制的是本站前端，不是防止外部客户端调用 API 的安全边界。

## 开销优化及边界

- 删除无 DOM 入口的 `contact-copy.js` 及其全站请求，少请求 968 字节的未压缩旧脚本。首页实际使用的复制功能在 `pages/home/recommendations.js`，继续保留。删除源文件可从 Git 历史恢复，未删除用户文件。
- `desktop-fixed-nav.js` 合并连续 refresh/resize 调度：最多保留一个待执行帧和两个延迟校准，不再每次事件新增三次测量。
- 可复现的单元测试中，初始化加两批各 100 次 refresh，在指定的两个帧时点及最终定时器执行后仅测量 4 次；旧调度会安排 603 次测量。这是调度模型的证据，不宣称真机帧率提高固定倍数。
- 新隐私脚本与样式合计 6,633 字节（含独立收起按钮的抽屉版，未压缩，不含模板及其他小改动），因此**没有将整项更新宣称为总下载字节减少**。新增功能自身有少量开销，旧无用请求和重复调度则已清理。
