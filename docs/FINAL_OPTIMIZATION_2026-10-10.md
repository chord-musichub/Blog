# 全站收尾优化 · 2026-10-10

本轮目标是减少前后台交互时的重复主线程工作，同时保护可见呈现、切页、布局与生命周期。最终保留共享语言模块的局部扫描与批处理优化；真实可见提示绘制没有退步。整页切换没有可认定的新收益，之前的预加载、搜索和动画优化不重复计分。

## 范围与实现

检查了页面切换与模块初始化、语言模块、工具与后台搜索、雪人弹簧、回忆滑动和音乐生命周期。旧电梯与星图搜索已在上一轮删除；`friends-search-panel` 仍有历史朋友模板消费者，继续保留。现有动画已有按需运行和离场释放，没有新增可比较收益的证据，因此不改动画参数、CSS、媒体格式或模块初始化规则。

唯一生产代码改动为 `static/js/i18n.js`，前台 `/js/i18n.js` 与后台 `/static/i18n.js` 沿用共享源文件：

- 刷新时只遍历声明的界面文字范围，嵌套范围只处理一次，正文不进入翻译文本遍历。
- 局部插入处理新增节点；同一父容器的批量插入合并扫描，纯移除不重新扫描整个父容器。整段受控文字移除仍处理其拥有者，避免旧内容被恢复。
- 以父链和 Set 去重任务，替代候选根之间的两两 `contains` 比较；所有临时集合在本次回调结束后释放，长期来源仍用 WeakMap。
- 直接修改 `data-i18n-text` 内文字节点时更新拥有者，修复既有英文界面残留中文的问题。
- 当前语言按钮的 `lang` 值相同时不重复写入。删除没有模板、脚本或动态加载消费者的 `<!--ui-->` 文字匹配分支；现有生产模板使用数据标记，压缩构建删除普通注释。

没有新增公开 API、持久化格式或权限变化，不修改用户内容。转场与简介打字节奏保持原值。可通过恢复优化前的单份 i18n.js 回退本轮生产改动。

## 同条件基线与结果

硬件 Intel Core i9-14900HX，Linux，Node 24.21.0，Chrome 154.0.8037.97，现有 Docker 镜像中的 Hugo 0.125.4 extended。优化前后均使用隔离、固定内容构建（68 页、183 静态文件），实际本地图片与动画开启；API 使用固定替身，第三方请求被本地测试 CSP 隔离。语言测量在相同暖页面执行，先预热两种语言；长内容场景追加 1,000 段固定中文正文，逐次断言原文与动态翻译输出。

1440×900 / 390×900，CPU 1× / 4×，普通与长正文共 8 组。前后交替两轮，每轮 60 次语言点击和 100 次动态提示插入；手机长正文 4× 追加三轮交替测量，共 6,080 次样本，观察 332.09 秒，内容断言或浏览器异常失败 0/6,080。原始失败尝试与最终结果分开保存，不合并收益。

### 呈现保护与测量局限

初始双 RAF 代理在个别压力组出现尾部差异。追加三轮手机压力测试，语言切换呈现代理合并后中位数为 81.5 → 81.0ms，p95 为 108.2 → 110.5ms；各次 p95 跨帧波动，方向反转，不计收益。动态插入的代理中位数为 31.4 → 33.2ms，p95 为 32.3 → 34.0ms。测试循环中上次移除节点的开销会改变下一输入的帧相位；增加起始帧对齐的专项测试后，动态插入代理中位数 43.8 → 43.7ms，p95 56.2 → 64.6ms，仍有尾部差异。这些结果完整保留，不用代理宣称真实呈现变快。

因此另用浏览器 Element Timing，将同样文案固定在视口内，记录翻译后文字的真实首次绘制；相同手机 4× CPU、1,000 段正文、暖页面，交替两轮，每轮 100 次提示，各 200 次，所有提示均为正确英文，0/400 失败。观察 25.76 秒：

| 可见首次绘制（ms） | 前 | 后 |
|---|---:|---:|
| 中位数 | 17.4 | 15.2 |
| p95 | 19.8 | 17.9 |
| IQR | 2.2 | 2.1 |
| 最小–最大 | 14.9–42.5 | 12.5–44.9 |

另一次独立探测的 p95 为 21.5 → 20.4ms。真实绘制未见退步，改善绝对值较小且受帧时序影响，不单独计分。Element Timing 与双 RAF 都不能代表真实用户 INP；点击排队时间、线上网络、真实手机、RSS、CPU/GPU 利用率和长期故障率均**未测量**。

### 批量正文保护与修正

初版仅排队新增节点，1,000 段一次插入产生过多小扫描：各 40 次中位数 3.1 → 6.4ms，p95 5.0 → 8.4ms，判定不能交付。修正为同父容器合并后，重新同条件比较各 40 次，中位数 3.1 → 2.2ms，p95 4.0 → 3.0ms，IQR 均 0.5ms；范围前 2.6–5.3ms、后 1.6–3.7ms。逐次核对 20 条标记文案和其余用户正文，0/80 失败。初版源码、数据与日志保留在忽略目录。
