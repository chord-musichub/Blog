# v20.18.5 修复反应测试低于 50ms 不同步 + 按账号/设备最佳排名

## 问题

反应测试测出 25ms 后没有同步到服务器。

## 根因

v20.15.0 的后端校验把反应测试分数限制为：

```text
50ms ~ 5000ms
```

所以 25ms 会被服务器拒绝。

## 本次修复

### 1. 放宽反应测试同步范围

反应测试是网页估测值，因此允许：

```text
1ms ~ 5000ms
```

### 2. 排行榜改成“每个账号/设备的最高纪录”

反应测试排行榜现在不再简单记录所有提交值，而是：

- 登录账号：按账号归并，只保留该账号最快成绩
- 未登录用户：按浏览器本地匿名 ID 归并，只保留该设备最快成绩
- 最后从所有账号/设备最佳成绩中取前三名

### 3. 排行榜显示来源

返回数据新增：

- `username`
- `display_name`
- `player_id`

前端会在排行榜里显示账号名或游客标识。

## 数据兼容

旧的 `reaction_scores.json` 仍然兼容。  
没有账号/设备信息的旧记录会作为 legacy 记录参与排序。
