# v20.18.5 贪吃蛇街机模式

## 策划方向

这版把贪吃蛇从“基础小游戏”推进成轻量街机模式，但不做太复杂的系统，避免一次改爆。

## 已落地机制

### 1. 连击系统

连续吃果实会叠连击：

- 连击会提高本次得分
- 约 5 秒未继续吃到果实，连击归零
- 黄星可以延长和强化连击

### 2. 新增道具果实

#### 金色护盾果

- 获得 1 层护盾
- 最多 3 层
- 撞墙或咬到自己时消耗 1 层护盾抵消死亡

#### 绿色缓速果

- 短时间降低游戏速度
- 适合高等级后救场

#### 黄色星尘

- 分数较高
- 强化连击
- 随机清除少量墙体

保留旧机制：

- 蓝色普通果实
- 棕色腐烂果实：生成墙
- 紫色脱皮果实：后半截蛇身变墙

### 3. 难度曲线

分数越高，等级越高，基础速度略微提高。  
绿果可以临时缓速，Shift 仍然可以主动加速。

### 4. 粒子反馈

吃果实、护盾触发、清除墙体时会出现轻量粒子文字反馈。

### 5. 生命周期修复

`snake.js` 现在导出：

```js
window.SonglineInitSnake
```

支持：

- 首次进入贪吃蛇页
- AJAX 切页进入贪吃蛇页
- pageshow 恢复
- 离开页面后清理旧键盘事件和 RAF 循环

## 后续可继续加的玩法

1. 限时挑战模式：90 秒内冲高分。
2. 每日种子地图：每天同一张地图，方便朋友之间比拼。
3. 任务系统：例如“吃 3 个星尘”“不用护盾到 100 分”。
4. 皮肤系统：蛇头/食物/地图主题。
5. Boss 果实：吃到后出现几秒移动障碍。
