# 文章权限、通知入口与旧网址残留修复

## 原因及修正

- 站主的列表筛选与访问判断排除了管理员稿件。现在站主可以在管理页看到、编辑和删除管理员文章；普通用户仍不能编辑别人的文章。审核发布权限仍只交给管理员，站主修改已发布稿件会进入原有的重新审核流程。
- 管理员被当成只能审核的账号，侧栏、新建及导入入口被关闭。恢复“发布通知”入口和创建/导入流程；系统账号发布内容继续由现有 `account_type=system` 规则自动归入站点公告。没有开放站点设置、项目、回忆或站主账号管理权限。
- 管理员修改已发布稿件后点“保存修改”，以前只改数据库，不处理旧网址目录；之后构建会生成新目录。现在该操作直接同步公开版本，并在改网址时备份移出旧目录。标题和网址变化不创建新的后台文章 ID。
- 历史清理只比较标题和发布时间，两项都可能改变，既会漏掉旧版本，也可能误判同名内容。新发布文件记录 `generated_by: songline-article` 和稳定的 `article_id`，构建时按 ID、状态、当前网址校验生成文件；失效的明确受管目录先备份再移出。无 ID 的历史文件不再按标题自动删除。
- 表单校验失败不再先下架公开文章；保存/删除的持久化失败会恢复内存记录。文章变更按顺序处理，文件移出与构建共用构建锁。提交/退回已发布稿件也会同步撤下公开版本。构建失败会明确提示，不宣称公开站已经更新。

## 已有服务器残留如何处理

只读 GET 核对时，用户给出的两个地址均返回 200：

- 新：`https://blog.songline-blog.com/posts/csapp-lab-guide/`，标题“CSAPP-lab导入”。
- 旧：`https://blog.songline-blog.com/posts/csapp-lab%E6%80%9D%E8%B7%AF/`，标题“CSAPP-lab思路”。

这证明旧网址仍在服务器提供内容，但仅凭公开 HTML 无法判断服务器后台记录和源目录的具体状态。没有登录服务器、部署或操作真实文件。

部署修复版后：

1. 用站主或管理员打开管理页 → **发布残留检查**（默认后台前缀下为 `/write/admin/publication-repair`）。检查本身是只读操作。
2. 找到 `csapp-lab思路` 对应项，先打开公开页，确认是旧版本；保留 `csapp-lab-guide`。
3. 勾选“已确认这是不再需要的旧发布目录”，点击“移入备份并重建”。服务端重新比对目录、当前稿件关联与文件指纹，过期的确认或当前稿件不能被这个入口移出。
4. 检查首页/文章列表只剩新版本、新网址正常、旧网址不再返回文章。如果前面有 CDN，再刷新相关页面缓存。

如果清单没有旧目录，可能只剩旧的 HTML 输出；正常 Hugo 重建已有 `--cleanDestinationDir`，会清除不再生成的旧 HTML。若重建后仍存在，需要核对服务器实际内容目录、发布目录和反向代理/CDN，不能反复点击删除来猜测。

备份位于实际 **DATA_DIR/backups/article-publication/<旧网址>-<随机后缀>/**。先完整复制整个文章目录，成功后才移出原目录，支持 data 与 content 分属不同挂载。目录与备份文件为私有权限，不进入 Hugo 公开数据。拒绝路径穿越、符号链接和特殊文件；不修改后台文章记录、不清理媒体库。

恢复前先停止后台写入/构建并确认原位置未被新稿件占用，把对应备份复制回原来的 `HUGO_CONTENT_DIR/<旧网址>`，核对内容后重建。带 ID 的目录若仍与数据库冲突，下次构建会再次移入备份，因此恢复正式文章还需先在后台恢复正确的稿件状态和网址。无 ID 的历史孤儿内容要经确认后恢复，不能把备份目录整体塞进公开目录。

## 验证证据

- Go 全量测试；新增管理员发通知、站主查找/编辑/删除、普通用户隔离、改名改网址只保留一条记录、错误表单不下架、历史残留人工确认、备份可恢复、路径/链接保护、持久化失败回滚测试。
- `TestArticleRealHugoRemovesOldPublicURLs` 使用真实 Hugo，在容器临时站点复现中文旧网址→新英文网址：验证旧 HTML 消失、新 HTML 正常；再模拟无 ID 历史残留，经过确认清理后首页只保留新文章，删除后新网址 HTML 也消失。
- 真实构建测试命令：`ARTICLE_REAL_HUGO=1 go test ./cmd/server -run '^TestArticleRealHugoRemovesOldPublicURLs$' -v`（需要本地 Hugo）。本次用已有 Docker 镜像，无网络、源码只读、测试数据写临时目录。
- Cookie 收起按钮的浏览器测试覆盖手机竖横屏、桌面、深浅主题、动画、快速反向操作、未选择/已同意时收起均不改变许可。

测试不是对线上数据执行清理。线上历史残留仍需部署后逐项确认处理。
