# v20.18.5 贪吃蛇临时豆连锁 + 全场清屏豆

## 新增玩法

### 临时豆连锁

粉色临时豆会限时出现。

吃到第一颗后，会开启 6 颗临时豆连锁挑战：

- 必须在倒计时内连续吃完
- 每颗临时豆分数递增
- 每吃一颗会略微补一点时间
- 全部吃完获得巨大完成奖励
- 超时后临时豆消失，连锁中断

这个机制类似马里奥里连续吃金币/踩怪的加成分逻辑，让玩家在短时间内做冒险路线选择。

### 全场清屏豆

黑色清屏豆极低概率出现。

吃到后：

- 清除全场所有墙
- 墙越多，分数越高
- 用于救场和扭转局面

## 设计原则

1. 不改变原本的基本贪吃蛇操作。
2. 不让新道具过于频繁，避免游戏失控。
3. 临时豆提供短时刺激。
4. 清屏豆提供极稀有的救场惊喜。
