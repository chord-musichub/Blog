# v20.18.5 音频可视化：本地助手读取系统声音 + 引导改版

## 问题

浏览器捕获窗口里不会出现“网易云音乐”这种桌面播放器选项，导致用户以为无法读取系统声音。

原因是浏览器 `getDisplayMedia` 的选择器不是“选择某个播放器的音频”，而是选择屏幕 / 窗口 / 标签页。系统音频通常要选整个屏幕并勾选共享音频，而且不同浏览器支持不一致。

## 本次修复

### 1. 本地助手新增系统声音频谱读取

`SonglineMusicBridge` 新增 NAudio WASAPI Loopback：

- 读取 Windows 默认输出设备
- 计算频谱 bands
- 提供 `/audio` 接口
- `/status` 同时返回媒体信息和音频状态

网页连接本地助手后，不需要在浏览器弹窗里找网易云程序。

### 2. 网页优先使用本地助手频谱

如果本地助手可用：

- 频谱来自 `http://127.0.0.1:23333/audio`
- 歌名/封面/进度来自 `http://127.0.0.1:23333/status`

浏览器捕获变成备用方案。

### 3. 引导界面重做

新增三张引导卡：

- 推荐：本地助手直读系统声音
- 备用：浏览器捕获
- 离线：上传本地音频

并明确说明：网易云 / QQ 音乐不会出现在浏览器捕获列表里。

### 4. 风格统一

界面改成更接近站点工具页的玻璃卡片 / 星云背景 / 状态胶囊风格。
