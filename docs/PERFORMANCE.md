# 加载与性能维护

维护目标是让现有页面稳定加载、及时释放旧页面任务，并减少重复请求和重复计算。修改时同时检查直开、站内切页、历史返回与后台恢复；具体模块边界见[前端架构](FRONTEND_ARCHITECTURE.md)。

## 页面何时显示

共享入口是 `web/static/resource-readiness.js`，公开站和后台跨文档过渡均使用它。当前预算由 `SonglineResources.policy` 集中维护：

| 对象 | 等待预算 | 行为 |
| --- | --- | --- |
| 主场景背景 | 8 秒 | 等待实际背景下载、解码及绘制帧，再退出覆盖层；超时后允许操作并显示仍在加载或失败状态 |
| 首屏次要图片 | 1.2 秒 | 超时保留占位，响应和解码成功后恢复显示 |
| 页面模块就绪 | 8 秒 | 有界等待初始化，避免无限阻塞 |

主场景与次要图片等待并行；预算是等待上限，缓存命中不固定停顿。背景提示只预热当前主题的实际场景，运行时仍检查真实 CSS。音频独立场景和已经隐藏的背景层不能附带下载其他场景图片。

图片观察期限为 30 秒，届时结束等待，但仍保留迟到响应的恢复路径。超时解除页面阻塞不等于全部图片已加载，也不等于浏览器取消了网络请求。当前场景状态通过 `data-scene-state` 区分，旧页面或旧图片源的响应不能覆盖新状态。

## 图片与网络

| 资源 | 当前策略 |
| --- | --- |
| 本地小图展示 | 支持的 JPEG/PNG 使用 `/uploads/…?preview=640`，工具图标使用 `preview=160`；详情放大与源文件保持原图 |
| 不适合转换的资源 | 外链、已有查询参数、WebP/GIF/SVG、特殊 PNG/CMYK JPEG 等保留原样或回退原图 |
| 正文图片 | 默认懒加载、异步解码；保留作者明确指定的属性，异步 Markdown 重渲染时尽量复用同源同属性图片元素 |
| 外部工具图标 | 距视口约 320px 时设置真实来源；使用官网资源地址，失败显示首字兜底 |
| 失败图片 | 网络恢复时对可见或邻近资源有限重试；同元素同来源最多一次，不对仍在下载的请求并行重试 |
| 可变媒体 URL | `Cache-Control: public, no-cache`，通过条件请求验证并返回 304；可存储但需验证 |
| 版本化 CSS/JS | 部署代理可长缓存，更新时保留完整版本 URL；样式同步保持实际层叠顺序 |

预览由 Go 服务按需生成，单次只解码一个任务，输入限制为 32 MiB / 2400 万像素，缓存上限为 256 MiB / 512 个文件。缓存键包含源文件状态、尺寸和算法版本；读取缓存前确认原图存在。生成失败或结果不更小时返回原图，不改写上传源文件。

## 减少重复工作

- 页面模块按实际 DOM 加载，初始化可重复调用；离场取消扫描、监听、帧任务与异步回调。
- 首页和音频工具复用播放列表节点，按变化更新文字、图标与频谱；页面隐藏时暂停视觉帧链，音频播放按自身规则保留。
- 工具搜索复用索引和卡片引用，只有状态变化时更新显示与计数。
- 翻译只扫描声明的界面范围；局部插入批量处理，正文不进入翻译遍历，来源使用 WeakMap 保存。
- 导航与阅读滚动按帧合并测量；保留用户点击时需要的实时命中检查。
- 阅读计数合并同路径并发请求，发送前再次检查统计许可；Markdown 下载超时使用文档内置源内容。

## 如何评价修改

使用同一份内容、视口、主题、浏览器和缓存条件对照，明确冷启动与缓存命中的差别。API 和第三方资源使用固定替身，不能改变真实用户数据。常规与专项命令见[测试与验证](TESTING.md)。

请求数量、源码字节、布局读取次数和 DOM/监听数分别说明不同工作量，不能直接换算为整站速度、帧率、GPU 显存或生产环境 Core Web Vitals。GPU 修改需要实际拖动、缩放和动画序列验证；手机视口模拟也不能代替 iOS/Android 真机。测试产物放在 `local-only/` 或临时目录，测量时注明浏览器、视口与缓存条件。
